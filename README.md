# NAI RICE - 인페인트 스튜디오

NovelAI 이미지 생성을 활용해서 **캐릭터의 감정 표정 세트**를  만드는 Windows 프로그램입니다.
캐릭터 챗봇에 쓸 기쁨·슬픔·분노 같은 표정 이미지를 만들 때 씁니다.

![감정 갤러리 화면](docs/images/NAI%20RICE.png)

인페인트로 레퍼런스 효과를 내는 방법(레퍼런스 인셋)을 자동화했습니다.

1. 캐릭터 그림을 캔버스 한쪽에 붙이고 나머지는 빈 칸으로 둡니다.
2. 빈 칸만 인페인트하면 NovelAI가 옆 그림을 보고 같은 캐릭터를 그립니다.
3. 감정마다 표정 프롬프트를 바꿔 반복하고, 빈 칸 부분만 잘라 감정별로 저장합니다.

웹 UI에서 감정마다 손으로 하던 캔버스 배치, 마스크, 프롬프트 교체, 자르기를 프로그램이 대신합니다.
Opus 구독이면 기본 해상도에서 Anlas가 들지 않습니다.

## 받기

[최신 릴리스](https://github.com/Rtyco/NAI-RICE/releases/latest)에서 `setup.exe`(설치판)나
`portable.exe`(포터블)를 받으면 됩니다.

## 쓰는 법

1. 왼쪽 아래 프로그램 설정에 NovelAI 토큰을 넣습니다.
2. 캐릭터 그림을 창에 끌어다 놓습니다.
3. 작업에서 캐릭터와 감정 모음을 고르고 생성을 누릅니다.

결과는 감정 갤러리에 모이고, 파일은 `문서\NAI RICE`에 저장됩니다.

## 기능

| 기능            | 하는 일                                                                                          |
| --------------- | ------------------------------------------------------------------------------------------------ |
| 작업            | 생성 설정·캐릭터·감정 모음·인페인트를 하나씩 골라 조합합니다. 각각 따로 저장해 두고 다시 씁니다. |
| 인페인트 캔버스 | 캐릭터 그림을 넣으면 해상도와 위치에 맞춰 캔버스와 마스크를 알아서 만듭니다.                     |
| 감정 모음       | 감정 이름과 표정 프롬프트 목록입니다. 기본 6종으로 시작해 얼마든지 늘릴 수 있습니다.             |
| 감정 갤러리     | 감정을 골라 한 번에 생성하고, 결과를 카드로 모아 봅니다.                                         |
| 감정 상세       | 대표 이미지를 고르고, 같은 seed로 다시 뽑거나 생성 정보를 확인합니다.                            |
| reference inset | 생성할 때 태그를 정해 둔 위치에 자동으로 넣습니다.                                               |
| 프롬프트 조각   | `<세트.조각>`으로 부르는 재사용 문구입니다. SD Studio 조각도 그대로 가져옵니다.                  |
| 태그 자동완성   | 프롬프트를 쓰면 단부루 태그 후보가 뜹니다. 인터넷 없이 동작합니다.                               |
| 이미지 불러오기 | NovelAI PNG를 끌어 놓으면 프롬프트와 설정을 골라서 가져옵니다.                                   |
| 생성 큐         | 요청을 차례로 처리하고, 일시적인 오류는 알아서 다시 시도합니다.                                  |
| 저장 공간       | 작업별 용량을 보고, 대표 이미지만 남기고 정리합니다. 지운 결과는 휴지통으로 갑니다.              |
| 단축키          | F1~F6 화면 이동, F11 전체 화면, Ctrl+N 새 작업 등을 씁니다.                                      |

## 알아 둘 것

- NovelAI와 관계없는 비공식 프로그램이라 생성에는 본인 계정의 토큰이 필요합니다.
- 코드 서명이 없어서 SmartScreen 경고가 뜰 수 있습니다. 「추가 정보 › 실행」으로 열면 되고, 걱정되면
  `certutil -hashfile 받은파일.exe SHA256` 값을 릴리스의 `SHA256SUMS.txt`와 비교해 보세요.
- 새 버전이 나오면 프로그램을 열 때 알려 줍니다.
- 결과 그림체는 참고 그림을 따라갑니다. 원본과 다르게 나오면 참고 영역을 넓히거나(세로 그림은 47%)
  작가 태그를 줄여 보세요. 실험 결과는 [인페인트 그림체 실험](docs/인페인트-실험.md)에 있습니다.

기능별 설명과 프롬프트 처리 방식은 [자세한 설명](docs/자세한-설명.md)에, 코드 구조와 개발 방법은
[개발 가이드](docs/개발-가이드.md)에 있습니다.
