# NAI RICE - 인페인트 스튜디오

NovelAI의 이미지 생성 기능을 활용하여 캐릭터의 씬(표정·상황) 이미지 세트를 제작하는 Windows 프로그램입니다.
캐릭터 챗봇 등에 사용할 기쁨·슬픔·분노 등의 감정 표현 이미지를 동일한 캐릭터로 여러 장 생성할 때 유용합니다.

![작업 갤러리 화면](docs/images/NAI%20RICE.png)

일반 생성(txt2img), i2i, 인페인트, 디렉터 툴, 캐릭터 레퍼런스, 바이브 기능을 모두 지원합니다.

## 다운로드 및 설치

[최신 릴리스](https://github.com/Rtyco/NAI-RICE/releases/latest)에서 `setup.exe`(설치판) 또는 `portable.exe`(포터블)를 다운로드하여 실행합니다. 이전 버전이 설치된 상태에서 덮어써도 기존 데이터는 그대로 유지됩니다.

## 기본 사용법

1. 창 상단 우측의 프로그램 설정에 NovelAI 계정 토큰을 입력합니다.
2. 기준이 될 캐릭터 이미지를 창으로 끌어다 놓습니다(Drag & Drop).
3. 작업 탭에서 캐릭터와 씬 모음을 선택한 후 생성을 시작합니다.

생성된 결과물은 작업 갤러리에 표시되며, 실제 파일은 `문서\NAI RICE` 경로에 저장됩니다.

## 인페인트로 일관된 캐릭터 생성하기

프로그램 이름의 '인페인트'는 인페인트 기능으로 레퍼런스 효과를 내는 기법(레퍼런스 인셋)을 자동화한 것에서 유래했습니다.

1. 원본 캐릭터 이미지를 캔버스 한쪽에 배치하고 나머지 영역은 빈칸으로 둡니다.
2. 빈칸 영역만 마스킹하여 인페인트하면, NovelAI가 옆의 원본 이미지를 참조하여 동일한 캐릭터를 그립니다.
3. 씬마다 프롬프트를 변경하며 이 과정을 반복한 뒤, 새로 그려진 영역만 잘라내어 씬별로 저장합니다.

기존 웹 UI에서 씬마다 수동으로 반복해야 했던 캔버스 배치, 마스킹, 프롬프트 교체, 이미지 자르기 과정을 프로그램이 자동으로 처리합니다. 캐릭터 레퍼런스 기능과 달리, Opus 구독자라면 기본 해상도 생성 시 Anlas가 소모되지 않습니다.

## 주요 기능

| 기능             | 설명                                                                                                                                                       |
| :--------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 작업             | 생성 설정, 캐릭터, 씬 모음, 인페인트 설정을 개별 저장하고 원하는 대로 조합하여 재사용합니다.                                                               |
| 생성 방식        | 작업별로 인페인트와 일반 생성 중 선택할 수 있으며, 기준 캐릭터 없이도 생성이 가능합니다.                                                                   |
| 인페인트 캔버스  | 캐릭터 이미지를 넣으면 해상도와 배치 위치에 맞춰 캔버스와 마스크를 자동으로 생성합니다.                                                                    |
| 씬 모음          | 씬 이름과 프롬프트로 구성된 목록입니다. 단일 이미지에서 디렉터 툴의 Emotion 기능을 활용해 씬 세트를 구축할 수도 있습니다.                                  |
| 작업 갤러리      | 원하는 씬을 선택해 일괄 생성하고 결과를 카드 형태로 모아 봅니다. 생성 전 예상 소모 Anlas가 표시됩니다.                                                     |
| 씬 상세          | 대표 이미지 지정, 확대·이동, 동일 시드 재생성 및 결과 다듬기를 지원합니다. 특정 씬 이미지를 해당 씬 프롬프트로 i2i 생성할 수 있습니다.                     |
| 자동 후처리      | 이미지 생성 시 발생하는 경계선(구분선)을 자동으로 감지해 제거하며, 결과물을 동일/타 모델이나 원본/변경된 프롬프트로 연속해서 다듬습니다.                   |
| 자유 생성        | 씬 세트 없이 단일 프롬프트만으로 생성합니다. i2i 및 직접 그리는 자유 인페인트 기능을 지원합니다.                                                           |
| 디렉터 툴        | 배경 제거(Remove BG), 표정 변경(Emotion) 등을 생성된 결과물에 즉시 적용합니다.                                                                             |
| 참고 (레퍼런스)  | 캐릭터 레퍼런스와 바이브를 라이브러리에 등록해 두고 칩(Chip) 형태로 간편하게 선택해 사용합니다. NovelAI 바이브 파일 로드를 지원합니다.                     |
| 다중 캐릭터      | 하나의 작업에 여러 캐릭터를 등록하고 각각의 위치를 지정합니다.                                                                                             |
| 프롬프트 조각    | 자주 쓰는 문구를 등록해 두고 `<세트.조각>` 문법으로 불러와 재사용합니다.                                                                                   |
| 찾아 바꾸기      | 프롬프트 입력창이나 라이브러리 전체에서 특정 태그와 이름을 찾아 일괄 변경합니다(`Ctrl+F`, `Ctrl+H`).                                                       |
| SD Studio 호환   | SD Studio 프로젝트를 불러와 상위·하위 프롬프트, 조합 프롬프트 및 기존 문법 그대로 생성하며, 작업을 다시 SD Studio 프로젝트로 내보낼 수 있습니다.           |
| 작업 파일        | 현재 작업에 사용된 항목들을 묶어 NAI RICE 전용 작업 파일로 내보내거나 가져옵니다.                                                                          |
| 태그 자동완성    | 프롬프트 입력 시 단부루(Danbooru) 태그 후보를 자동으로 추천합니다. 오프라인 환경에서도 동작합니다.                                                         |
| 다중 계정 관리   | 여러 개의 NovelAI 계정을 등록해 두고, V5 무료 할당량이 소진되면 자동으로 다음 계정으로 전환합니다.                                                         |
| 토큰 표시줄      | 실제 전송될 프롬프트의 토큰 수를 NovelAI 웹 환경처럼 모델별 한도와 함께 막대그래프로 보여 줍니다.                                                          |
| 이미지 불러오기  | NovelAI에서 생성된 이미지를 끌어다 놓으면 메타데이터에서 프롬프트, 설정, 캐릭터 위치 등을 선택하여 가져옵니다.                                             |
| 생성 큐          | 생성 요청을 순차적으로 처리하며, 네트워크 등 일시적인 오류 발생 시 자동으로 재시도합니다.                                                                  |
| 저장 공간 관리   | 결과물을 무손실 WebP 포맷으로 저장하여 용량을 아끼고, 대표 이미지만 남긴 채 정리할 수 있습니다. 삭제된 파일은 휴지통으로 이동합니다.                       |
| 집중 모드        | `Tab` 키로 전체 패널을 한 번에 숨기거나, `F6`~`F9` 키로 개별 패널을 접어 작업 공간을 확보합니다.                                                           |
| 반응형 화면 배치 | 좁은 창, 200% 배율, 모바일 화면 폭에 맞춰 패널이 자동으로 접히며, 터치스크린 두 손가락 확대를 지원합니다. UI 간소화 시 사이드바를 아이콘으로만 표시합니다. |
| 단축키 지원      | 숫자 키 `1`~`8` 화면 전환, `F1` 단축키 도움말, `F2` 이름 변경, `Ctrl+휠` 화면 확대/축소 등 다양한 단축키를 지원합니다.                                     |

## 참고 및 주의사항

- 본 프로그램은 NovelAI와 무관한 비공식 서드파티 프로그램이므로, 이미지 생성을 위해서는 본인 계정의 접속 토큰이 필요합니다.
- 캐릭터 레퍼런스, 바이브, 디렉터 툴 사용 및 고해상도 생성 시에는 Opus 구독자라도 Anlas가 소모됩니다. 생성 전 표시되는 예상 Anlas를 반드시 확인하세요.
- 코드 서명이 적용되지 않아 실행 시 Windows SmartScreen 경고가 발생할 수 있습니다. 「추가 정보 › 실행」을 눌러 실행할 수 있으며, 파일 변조가 우려되는 경우 명령 프롬프트에서 `certutil -hashfile 받은파일.exe SHA256` 명령어로 추출한 해시값을 릴리스 페이지의 `SHA256SUMS.txt`와 대조해 보시기 바랍니다.
- 새로운 버전이 출시되면 프로그램 실행 시 업데이트 알림이 표시됩니다.
- 인페인트 생성 시 결과물의 그림체는 원본(참고) 이미지를 따라갑니다. 만약 원본과 그림체가 다르게 나온다면 참고 영역 비율을 넓히거나(세로 이미지 기준 47% 권장) 프롬프트의 작가 태그를 줄여 보세요. 관련 테스트 결과는 [인페인트 그림체 실험](docs/인페인트-실험.md) 문서에서 확인할 수 있습니다.

각 기능에 대한 상세 설명과 내부 프롬프트 처리 방식은 [자세한 설명](docs/자세한-설명.md) 문서를 참고하세요.
