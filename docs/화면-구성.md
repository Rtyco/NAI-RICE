# 화면 구성과 이름

NAI RICE의 화면을 무엇이라 부르는지 정리한 문서입니다. 기능을 요청하거나 코드를 찾을 때 이 이름을 씁니다.
괄호 안은 코드에서 찾을 이름(컴포넌트·CSS 클래스)입니다.

## 큰 틀

```text
[사이드바] [왼쪽 패널] [ 화면 머리줄            ] [오른쪽 패널]
                       [ 구성 막대              ]
                       [ 가운데 (본문)          ]
[사이드바] [ 생성 큐 막대 ······················· 생성 묶음 ]
```

왼쪽부터 사이드바, 왼쪽 패널, 가운데 세 줄(머리줄·구성 막대·본문), 오른쪽 패널 순서입니다. 생성 큐 막대는
사이드바 오른쪽 맨 아래에 가로로 깔립니다.

창 제목 표시줄은 따로 없습니다. 맨 위 줄들(사이드바 이름 줄, 왼쪽 패널 머리, 화면 머리줄)을 끌면 창이 옮겨지고,
Windows 창 버튼(최소화·최대화·닫기)은 화면 머리줄 오른쪽 위에 겹쳐 나옵니다. 화면 머리줄은 그만큼 오른쪽을
비워 둡니다. 머리줄이 없는 시작 화면에는 얇은 줄(`window-strip`)을 둡니다.

- **사이드바** (`Sidebar`): 맨 왼쪽. 어느 화면에서나 보입니다. Ctrl+B로 아이콘만 남게 접습니다.
- **왼쪽 패널**: 화면마다 다릅니다. 작업·자유 생성은 **프롬프트 패널**, 라이브러리는 **라이브러리 목록**입니다.
- **가운데 (본문)**: 그 화면의 주된 내용입니다. 이미지·캔버스·카드가 여기에 나옵니다.
- **오른쪽 패널 (입력 패널)** (`detail-side`, `canvas-settings`): 씬 상세·자유 생성·인페인트 편집에만
  있습니다. 생성에 넣을 값을 두고, 씬 상세·자유 생성은 맨 아래에 생성 버튼도 붙입니다.
- **생성 큐 막대** (`QueueBar`): 맨 아래. 왼쪽은 큐, 오른쪽은 화면마다 다른 생성 묶음(`BottomSlot`)입니다.

### 패널 폭 조절

사이드바, 왼쪽 패널, 오른쪽 패널은 경계를 끌어 폭을 바꿉니다. 이런 기능은 보통 **패널 크기 조절(리사이즈)**
이라 하고, 끄는 경계 막대를 **스플리터(splitter)** 또는 **리사이즈 핸들**이라 부릅니다. 코드에서는
`PanelResizer`(손잡이)와 `panelWidths.ts`(폭 기억)입니다.

- 끌기: 폭 바꾸기 · 두 번 누르기: 기본 폭 · 손잡이에 포커스가 있을 때 ←/→: 16px씩
- 오른쪽 패널은 씬 상세·자유 생성·인페인트 편집이 같은 폭을 씁니다.
- 폭은 다음 실행에도 기억합니다(`localStorage`의 `panel-width:<패널>`).

| 패널            | 기본 폭 | 범위      |
| --------------- | ------- | --------- |
| 사이드바        | 240px   | 200~400px |
| 라이브러리 목록 | 260px   | 200~480px |
| 프롬프트 패널   | 300px   | 240~600px |
| 오른쪽 패널     | 360px   | 280~640px |

## 사이드바

위에서부터:

1. **자유 생성**: 자유 생성 화면으로 갑니다.
2. **작업** 카드: 작업 목록. 제목 줄을 누르면 접히고, ＋는 새 작업(Ctrl+N)입니다. 작업은 **목록 폴더**로
   묶을 수 있습니다(아래 「목록 폴더」).
3. **라이브러리** 카드: 생성 설정(F2)·캐릭터(F3)·씬 모음(F4)·인페인트(F5)·프롬프트 조각(F6). 누르면
   라이브러리 화면의 그 칸으로 갑니다.
4. 아래 줄: JSON 가져오기(Ctrl+O), 작업 폴더 열기, **프로그램 설정**(Ctrl+,).

## 화면 (가운데에 오는 것)

### 시작 화면 (`Welcome`)

작업이 없거나 아무것도 고르지 않았을 때 나옵니다. 새 작업·JSON 가져오기·프로그램 설정 버튼이 있습니다.

### 작업 화면 (`ProjectView`)

작업 하나를 여는 화면입니다. 위에서부터:

- **화면 머리줄** (`project-header`): 작업 이름, **모드 버튼** [인페인트 | 일반 생성], **계정 표시**
  (`AccountMeter`, V5 무료 할당량·Anlas), **⋯ 메뉴**(최종 요청 미리보기·작업 폴더 열기·복제·삭제).
- **구성 막대** (`chain-bar`): 이 작업이 쓰는 라이브러리 항목을 고르는 **구성 칩**(`ChainChip`)들. 칩에는 지금
  고른 이름만 보이고, 누르면 칩 아래에 **고르기 창**(`ChecklistChip`)이 뜹니다. 고르기 창은 라이브러리 항목을
  목록 폴더대로 보여 주고, 지금 쓰는 항목에 체크와 강조색이 있습니다. 폴더 제목을 누르면 접히고(라이브러리
  목록과 따로 기억), 접힌 폴더에도 고른 항목 수가 보입니다. 줄에 마우스를 올리면 연필(편집 팝업)이
  나오고, 아래에 「라이브러리에서 관리」가 있습니다. 칩에 마우스를 올려도 연필 버튼이 나옵니다. 일반 생성
  모드에서는 인페인트 칩 대신 해상도 칩이 나옵니다.
  - **캐릭터 칩** (`CharacterChip`): 고른 캐릭터 이름(셋부터는 「첫 이름 외 N명」). 고르기 창에서 여럿을 체크할
    수 있고, 체크 대신 고른 순서 번호가 보입니다. 고른 줄에는 프롬프트 세트 선택과 「앞 순서로 옮기기」가
    붙습니다. 순서가 씬 프롬프트 칸의 순서이고, 인페인트의 참고 이미지는 첫 캐릭터만 참고가 됩니다.
  - **위치 칩** (`PositionChip`): 「AI가 정함」/「직접 지정」. 누르면 **캐릭터 위치** 창이 열립니다.
- **경고 띠** (`missing-banner`): 생성에 필요한 것이 빠졌을 때만 나옵니다.
- **본문**: 아래 둘 중 하나입니다.

#### 작업영역 (갤러리, `GalleryView`)

씬마다 카드 한 장씩 늘어선 화면입니다.

- **카드 막대** (`gallery-toolbar`): 위쪽. 왼쪽은 **카드 고르기**(모두 고르기, Ctrl+A). 카드를 고르면 같은
  자리가 **고른 카드 막대**로 바뀝니다(i2i로 보내기·결과만 삭제·씬 삭제·고르기 취소). 오른쪽은 내보내기,
  **카드 비율** 아이콘(세로 832×1216·가로 1216×832·정사각 1024×1024, NovelAI 기본 해상도와 같은 비율)과 **한 줄 카드
  수**(3~7).
- **씬 카드** (`EmotionCard`): 대표 이미지(없으면 최신), 아래에 **생성 체크**(일괄 생성에 넣을지), 씬 이름,
  장수. 마우스를 올리면 카드 오른쪽 위에 ▶(이 씬만 생성)와 ⋯(메뉴)가 세로로 겹쳐 나옵니다(카드 크기는 그대로).
  - **카드 고르기**(Ctrl·Shift 클릭, 빈 곳 끌기)는 삭제·i2i 같은 일괄 작업 대상이고, **생성 체크**는 일괄
    생성 대상입니다. 둘은 다릅니다.
- **생성 묶음** (생성 큐 막대 오른쪽): 생성할 씬 N/M, 모두 체크·모두 해제, × 씬마다 장수, 예상 Anlas, ▶ 생성.

#### 씬 상세 (`EmotionDetail`)

씬 카드를 눌러 들어가는 화면입니다.

- **씬 이동 막대** (`detail-nav`): ← 갤러리, **씬 ⋯ 메뉴**(씬 복제·씬 삭제), 오른쪽에 ‹ 이전 · n/m · 다음 ›.
- 가운데:
  - **미리보기** (`ImageStage`): 고른 결과를 크게 봅니다. 휠로 커서 위치를 기준으로 확대, 왼쪽(또는 가운데)
    버튼으로 끌어 화면 안 어디로든 이동, 도구 막대의 **가운데로**(⌖)로 자리 되돌리기, 배율 숫자를 누르면 맞춤과
    가운데로, 더블클릭으로 맞춤·원본 크기, 원본 크기 창. 다른 결과로 넘겨도 배율과 자리는 그대로입니다.
  - **결과 막대** (「선택한 결과」, `ResultBar`): 미리보기 바로 아래. ⓘ 생성 정보 | 대표 지정·이 seed로
    다시·프롬프트 복원 | i2i로 보내기·자유 생성 i2i·인페인트 만들기 …… 오른쪽 끝에 저장·폴더에서 보기·이
    결과 삭제. 이미지를 우클릭하면 같은 목록이 메뉴로 나옵니다(`ResultActions`).
  - **이미지 목록** (필름 스트립, `filmstrip`): 이 씬의 결과를 최신순으로 늘어놓습니다. 접을 수 있습니다. 여러
    장을 골라 한꺼번에 지울 수 있고, 아래 줄(`filmstrip-bar`)에 고른 장수와 삭제가 나옵니다.
- **오른쪽 패널**: 씬 이름, 씬 프롬프트(캐릭터가 여럿이면 캐릭터마다 한 칸, `ScenePromptFields`), 일괄 생성에
  포함, 아래에 붙은 **생성 독**(`generate-dock`, 생성 수·생성 버튼).
- 단축키: ←/→ 결과 이동, Del 결과 삭제, Tab/Shift+Tab(또는 PageDown/PageUp) 씬 이동, Esc 갤러리.

### 자유 생성 (`FreeView`)

씬 없이 프롬프트만으로 여러 장 뽑는 화면입니다. 결과는 작업과 따로 `projects/free/`에 쌓입니다.

- **화면 머리줄**: [일반 생성 | i2i] 버튼, 계정 표시, 결과 폴더.
- **구성 막대**: 생성 설정·캐릭터(없음 가능, 여럿 가능)·위치·해상도 칩. 작업 화면과 같은 고르기 창을 씁니다.
- 가운데: 씬 상세와 같은 미리보기·결과 막대·이미지 목록. i2i일 때는 위에 **[i2i 이미지(또는 마스크 칠하기) |
  원본과 결과]** 탭이 있습니다.
- **오른쪽 패널**: i2i일 때 **i2i 이미지 카드**(이미지, 전체 다시 그리기/인페인팅, 강도·노이즈), 프롬프트,
  **붙일 위치**, 아래 생성 독(장수·예상 Anlas·생성).

### 프롬프트 패널 (`PromptPanel`)

작업 화면과 자유 생성의 왼쪽 패널입니다. 구성 막대에서 고른 생성 설정의 공통 포지티브·네거티브와 캐릭터
프롬프트 세트를 바로 고칩니다. 생성 설정 한 장과 「캐릭터 프롬프트」 묶음 아래 캐릭터마다 한 장씩
**프롬프트 카드**(`PromptCard`)가 순서대로 쌓입니다. 카드 제목 줄을 누르면 접히고, 접힌 카드에는 포지티브
첫머리만 보입니다. 카드 제목 줄과 내용은 배경색이 달라 한 캐릭터의 범위가 보입니다. 캐릭터가 여럿이면 「모두 접기」로 한꺼번에 접습니다. 접은 상태는 다음 실행에도 기억합니다.
값은 라이브러리 항목에 저장되므로 같은 항목을 쓰는 다른 작업에도 반영됩니다.
왼쪽 위 버튼으로 접습니다. 작업 화면에서는 아래에 「최종 요청 미리보기」가 있습니다.

### 라이브러리 (`LibraryView`)

여러 작업이 함께 쓰는 재료를 보관하는 화면입니다.

- **라이브러리 목록** (`library-list`): 왼쪽. 항목 목록, ＋ 추가, 접기. 우클릭 메뉴(`listMenu`)와 목록 폴더는
  사이드바 작업 목록과 같습니다.
- **편집기** (`library-editor`): 오른쪽. 위 **편집기 머리줄**(이름·사용 중인 작업·폴더 열기·JSON
  내보내기·복제·삭제), 아래 칸별 편집기:

| 칸            | 편집기             | 담는 것                                                               |
| ------------- | ------------------ | --------------------------------------------------------------------- |
| 생성 설정     | `PresetEditor`     | 공통 프롬프트, 모델, 일반 생성·i2i, 품질 태그·UC 프리셋, 샘플링, Seed |
| 캐릭터        | `CharacterEditor`  | 캐릭터 프롬프트 세트(의상·버전별 포지티브·네거티브)                   |
| 씬 모음       | `EmotionSetEditor` | 씬 이름과 씬 프롬프트 목록. ＋로 두 번째 캐릭터부터의 칸을 엽니다     |
| 인페인트      | `ReferenceEditor`  | 참고 이미지와 캔버스(아래 「인페인트 편집」)                          |
| 프롬프트 조각 | `PieceSetEditor`   | `<세트이름.조각이름>`으로 불러 쓰는 조각                              |

같은 편집기를 작업·자유 생성 화면에서 **편집 팝업**(`LibraryEditorDialog`)으로도 엽니다.

#### 인페인트 편집 (`ReferenceEditor`)

- 가운데 **캔버스** (`ReferenceCanvas`):
  - 위 **캔버스 도구 막대**: [영역 상자: 참고 영역·결과 영역] | [붓: 칠하기·지우기·모양·크기] |
    [반전·모두 지우기·↶↷] …… [보기: 불투명도·확대].
  - 아래 **상태 줄**: 저장 크기, 무료 크기 여부, 경고.
- **오른쪽 패널**: 카드 세 장. **참고 이미지**(이미지 고르기), **캔버스 구성**(자동 구성/직접 준비한 캔버스,
  해상도, 위치, 비율, 맞춤, 배경색, 되돌리기), **영역**(참고 영역 여백, 결과 영역 숫자).
- 영역 이름:
  - **참고 영역**: 참고 그림이 있는 곳. 다시 그리지 않습니다.
  - **결과 영역**: 생성한 뒤 잘라서 저장할 곳.
  - **생성 영역**(청록색): NovelAI가 새로 그리는 곳. 붓으로 칠합니다.

### 목록 폴더 (`ListFolder`)

사이드바 작업 목록과 라이브러리 목록의 항목을 폴더로 묶습니다. 한 단계만 있습니다.

- 묶기: 항목을 고르고(Ctrl·Shift 클릭, 빈 곳에서 끌기) **Ctrl+G**, 또는 우클릭 「폴더로 묶기」나 선택 막대의
  「묶기」. 고른 것이 없으면 지금 보고 있는 항목 하나를 묶습니다. 묶으면 바로 폴더 이름을 바꾸는 칸이 열립니다.
- 폴더 제목: 누르면 접고 펴며, 두 번 누르면 이름을 바꿉니다. 이미 있는 이름으로 바꾸면 그 폴더와 합칩니다.
  우클릭하면 접기·이름 변경·안의 항목 모두 선택·폴더 풀기가 있습니다.
- 끌어 놓기: 항목을 폴더 제목에 놓으면 그 폴더 끝으로, 다른 항목에 놓으면 그 항목 옆(그 항목의 폴더)으로
  들어갑니다. 폴더 제목을 끌면 폴더째 자리를 옮깁니다. 우클릭 「폴더에서 빼기」로 꺼냅니다.
- 폴더는 항목의 `folder` 이름으로만 저장되므로 항목이 모두 빠지면 사라집니다. 사이드바를 좁게 접으면 폴더
  없이 항목만 보입니다.
