# 4단계: i2i와 업스케일 우회

## 0단계에서 확인한 것

- **요청:** `action: 'img2img'`, `image`, `strength`, `noise`, `extra_noise_seed`(= seed). V4 이상은
  `img2img: { strength, noise, begin_from_sigma: null, extra_noise_seed, color_correct: true }`도 같은 값으로
  넣습니다. `mask`, `inpaintImg2ImgStrength`, `add_original_image`는 뺍니다. 2단계의
  `buildNovelAIDiffusionRequest`가 `Img2ImgJobSnapshot`(`strength`, `noise`)으로 이 본문을 만듭니다.
- **크기:** 서버는 입력 이미지를 요청한 `width`×`height`로 **비율을 무시하고 늘립니다**(832×1216 입력을
  1024×1024로 요청하면 얼굴이 옆으로 퍼짐). **앱이 보내기 전에 목표 비율에 맞춰 자르거나 여백을 넣어야
  합니다.** 작은 입력(416×608)을 832×1216으로 요청하는 것은 문제없고 차감도 없습니다.
- **업스케일 우회:** 416×608 → 832×1216, strength 0.4에서 얼굴과 구도는 유지되고, 단순 확대보다 선과 눈이
  선명하게 다시 그려집니다. 머리카락 그늘 색이 조금 바뀝니다. 기본값 실험은 0.3~0.5에서 합니다.
- **비용:** 무료 조건(Opus, 1024×1024 이하, 28스텝 이하) 안에서는 0. 넘으면 계산식 값에 strength를 곱해
  올림하고 최소 2입니다(`NaiCost.ts`에 이미 있음).
- **투명 배경:** 불투명 입력으로 i2i하면 V5 `transparent background` 태그를 넣어도 투명해지지 않습니다.
- **V5 할당량:** i2i가 두 배 든다는 말이 있지만 확인하지 못했습니다(9건 동안 표시가 10%에서 변하지 않음).
- **NovelAI 업스케일:** `image.novelai.net/ai/upscale`은 본문에 `model`이 필요한데 값을 모릅니다. 비교가 필요하면
  웹 요청을 확인해 다시 시험합니다.

## 4-1. i2i 모드

- 이미지 한 장과 strength를 정하고 i2i로 생성합니다. 감정 모드(감정마다 i2i)와 자유 생성 화면 모두에서
  씁니다.

## 4-2. 결과를 i2i로 보내기 (업스케일 우회)

크롭된 결과를 832×1216 같은 큰 크기로 늘려 i2i로 다시 그리면 무료 범위 안에서 해상도를 올릴 수 있습니다.

- 감정 상세, 갤러리 우클릭 메뉴, 자유 생성 결과에 "i2i로 보내기"를 넣습니다.
- 대화 상자 값: 목표 크기(무료 해상도 프리셋, 원본 비율에 가장 가까운 것을 기본 선택), strength, 프롬프트
  (원래 프롬프트 재사용 기본), 생성 장수, 예상 Anlas.
- 결과는 같은 감정(또는 같은 자유 생성 세션)에 새 결과로 쌓이고, `sourceRecordId`로 원본을 표시합니다.
- "선택한 감정의 대표 이미지 모두 i2i로" 일괄 실행을 넣습니다.
- 무료 범위 실험으로 strength 기본값을 정합니다(그림체·얼굴 유지와 선명도의 균형).

## 결과 (2026-10-10, 사용자 확인 전)

- **입력 준비(메인 프로세스):** `Library.prepareImageInput`이 결과·인페인트 원본·올려 둔 파일을 목표 크기로
  맞춰 작업의 `inputs/<sha256>.png`에 넣습니다. crop은 위쪽을 남기고 자르고, pad는 가운데에 두고 흰 여백을
  넣습니다. 투명한 부분은 흰색으로 합칩니다(0단계는 불투명 입력만 시험함). 파일에서 고른 이미지는
  `storeImageInput`으로 먼저 PNG로 넣어 둡니다.
- **세기·노이즈:** `GenerationSettings.img2imgStrength`(기본 0.4, 0단계 결과)·`img2imgNoise`(기본 0). 생성
  설정의 「일반 생성 · i2i」 칸과 구성 막대의 「i2i 세기」 칩에서 바꿉니다.
- **i2i 원본 라이브러리(사용자 결정):** 처음에는 작업 i2i가 인페인트의 원본 이미지를 써서 무엇을 다시
  그리는지 헷갈렸습니다. 그래서 라이브러리에 「i2i 원본」을 따로 두었습니다(`Library.img2imgSources`, 파일은
  `sources/<해시>.png`). 파일에서 추가하거나 결과의 「i2i 원본에 추가」로 넣고, 「인페인트로 만들기」로
  인페인트 라이브러리에 옮깁니다.
- **4-1 작업의 i2i 모드:** 모드 버튼 [i2i]. 「i2i 원본」 칩에서 고른 이미지를 생성 설정의 해상도로 잘라
  맞춘 뒤 감정마다 i2i합니다(`buildImg2ImgJobs`). 갤러리 위 띠에 원본과 목표 크기를 보여 줍니다.
  reference inset은 붙이지 않습니다.
- **4-1 자유 생성 i2i:** [일반 생성] [i2i]를 고르고 「i2i 원본」 칩이나 결과의 「i2i 원본으로」로 원본을
  정합니다. 원본이 같은 곳의 결과면 `sourceRecordId`가 남습니다.
- **입력 확인:** i2i 결과는 실제로 보낸 입력(`inputFile`)을 기록하고 생성 정보에 보여 줍니다.
- **4-2 i2i로 보내기:** 감정 상세·자유 생성의 선택한 결과, 감정 카드 우클릭 「대표 이미지 i2i로」, 갤러리에서
  여러 감정을 고른 뒤 「대표 이미지 i2i로」. 대화 상자에서 목표 크기(원본 비율에 가장 가까운 무료 해상도가
  기본), 맞추는 방법, 세기, 노이즈, 장수, seed(원본부터 +1 또는 무작위)를 고릅니다. 원래 결과의 최종
  프롬프트·설정을 그대로 쓰되 reference inset 태그는 뺍니다(`buildResultImg2ImgJobs`). 결과는 원래 감정에
  `sourceRecordId`와 함께 쌓입니다.
- 남은 것: 실제 NovelAI로 무료 범위에서 세기 기본값(0.3~0.5)을 사용자와 확인합니다.
