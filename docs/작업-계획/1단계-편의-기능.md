# 1단계: 편의 기능 (완료)

기록용입니다. 이 기능을 다시 고칠 때만 읽습니다.

## 계획

- **1-1. 사이드바 섹션 접기:** 「작업」, 「라이브러리」 제목을 누르면 그 카드가 접힙니다. 접힌 상태는 다시 켜도
  유지합니다. 사이드바 전체 접기(Ctrl+B)는 그대로 둡니다.
- **1-2. 인페인트 마스크 비우기:** 마스크 도구에 생성 마스크를 모두 지우는 버튼. 실행 취소(Ctrl+Z) 가능. 마스크가
  비면 생성이 막혀야 합니다.
- **1-3. 예상 Anlas 표시:** 0단계 계산식으로 예상 비용을 계산해 생성 버튼 옆, Anlas 확인 창, 큐 항목에
  보여 줍니다. 실제 차감량과 다를 수 있으므로 화면에는 항상 "예상"이라고 씁니다.

## 결과

- **1-1:** 사용자 결정에 따라 세로로만 접습니다. 접힌 카드는 제목 줄만 남고 펼쳐진 카드가 남는 높이를 씁니다.
  사이드바 너비는 그대로입니다. 상태는 Ctrl+B 상태처럼 `localStorage`(`sidebar-sections-collapsed`)에
  저장하고, 좁은 막대(Ctrl+B)에서는 무시하고 아이콘을 모두 보여 줍니다.
  - 사용자 요청으로 제목 줄 전체를 누를 수 있게 했고(작업 카드의 + 버튼은 그대로 오른쪽 위), 접고 펴는
    애니메이션을 앱의 움직임(240ms, `cubic-bezier(0.2, 0.8, 0.2, 1)`)에 맞췄습니다. 높이 애니메이션은
    `interpolate-size: allow-keywords`로 `height: auto`를 씁니다.
- **1-2:** 「마스크 비우기」는 모든 픽셀을 보호로 고정합니다(실행 취소 가능). 계획은 빈 마스크면 "지금처럼"
  생성이 막힌다고 봤지만, 실제로는 편집 화면 경고만 있고 생성은 막히지 않았습니다. 메인 프로세스의
  `prepareInputs`(`electron/services/Library.ts`)가 마스크 PNG에 생성 픽셀이 없으면 요청 전에 오류를 내도록
  고쳤습니다.
- **1-3:** `NaiCost.ts`의 `imageAnlasCost`(계산식), `estimateJobAnlas`(무료 판단 포함).
  - 계정 상태에 구독 등급(`tier`)을 추가했습니다. Opus가 아니면 확인 창에 이유가 하나 더 붙습니다. 등급을
    아직 모르면 지금까지처럼 Opus로 봅니다.
  - 표시: 생성 버튼 옆 "예상 0 Anlas (무료)" / "예상 약 N Anlas"(이유는 툴팁), 확인 창의 예상 합계, 큐 항목의
    예상값과 실제 차감량. 큐 항목의 예상값은 메인 프로세스가 큐에 넣을 때 계산해 `anlasEstimate`로 저장합니다.
  - V5 "할당량 약 n%"는 0단계에서 소모량을 확인하지 못해 넣지 않았습니다.
