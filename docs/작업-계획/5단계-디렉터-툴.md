# 5단계: 디렉터 툴 (구현, 사용자 확인 전)

## 0단계에서 확인한 것

- **요청:** `POST https://image.novelai.net/ai/augment-image`, 본문
  `{ req_type, width, height, image, prompt?, defry? }`. 2단계의 `buildNovelAIAugmentRequest`가
  `AugmentJobSnapshot`(`tool`, `mood`, `toolPrompt`, `defry`)으로 만듭니다.
- **응답:** 생성과 같은 ZIP. 결과 PNG의 `Comment`에는 `req_type`(Emotion은 `prompt`, `defry`도)만 있고
  `Source`는 없습니다.

| req_type     | 832×1216 차감 | 응답                                                            |
| ------------ | ------------- | --------------------------------------------------------------- |
| `emotion`    | 0             | RGB 1장. `prompt: "<감정>;;<추가 문구>"`, `defry: 0~5`          |
| `bg-removal` | **65 Anlas**  | RGBA **3장**(`image_0~2`), 모두 배경 투명. 셋이 무엇인지는 모름 |
| `declutter`  | 0             | RGB 1장                                                         |
| `lineart`    | 0             | RGB 1장. 흑백 선화                                              |
| `sketch`     | 0             | RGB 1장. 연필 스케치                                            |
| `colorize`   | 0             | RGB 1장. 프롬프트가 없으면 머리·눈 색이 바뀜                    |

- **배경 제거만 유료**이고 Opus여도 무료가 아닙니다. 실행 전 확인 창이 꼭 필요합니다. 크기별 비용은 모릅니다.
  지금 `NaiCost.ts`는 832×1216의 65에 크기를 비례시켜 대략 추정합니다. 사용자 허락을 받고 한 장씩 시험해
  확인합니다.
- **Emotion:** `angry`, `sad`는 얼굴만 바뀌고 머리·옷·포즈·배경은 그대로입니다. 감정 세트 만들기에
  적합합니다. `defry: 3`(약하게)도 눈물은 남고 표정이 조금 덜할 뿐이라 강도 차이는 크지 않습니다. 이미 웃는
  입력에 `happy`는 변화가 거의 없습니다.

## 할 일

- 결과 하나에 툴을 적용합니다: **Emotion, 배경 제거, Declutter**를 주요 메뉴로, Line Art·Sketch·Colorize는
  하위 메뉴로 둡니다.
- 결과는 새 결과로 저장하고 `sourceRecordId`를 남깁니다. 배경 제거는 세 장을 어떻게 저장할지 정합니다.
- **Emotion 툴로 감정 세트 만들기:** 대표 이미지 한 장(중립)을 골라, 감정 모음의 감정마다 Emotion 툴을
  돌립니다. 몸·옷·포즈가 같은 세트가 나옵니다.
  - 감정 모음의 감정 항목에 Emotion 툴용 값(툴이 받는 감정 이름, 강도)을 선택 사항으로 추가합니다.
  - NovelAI 문서: 정면을 보는 중립 표정의 캐릭터 한 명일 때 가장 잘 됩니다.
- 실행 전에 항상 예상 비용을 보여 줍니다.

## 결과

2026-10-12에 구현했습니다. 실측과 사용자 확인이 남았습니다.

- **기반:**
  - `buildResultAugmentJobs`가 결과 하나로 디렉터 툴 작업을 만듭니다. 원래 결과의 프롬프트·설정·seed는 요청에
    쓰지 않지만 결과 정보에 남도록 옮깁니다. `targets`를 주면 씬마다 하나씩 만듭니다(씬 세트).
  - provider는 응답 ZIP의 PNG를 이름 순서대로 모두 돌려줍니다. 큐는 장마다 결과를 하나씩 저장하고(파일 이름 끝
    `__2`, `__3`), Anlas는 첫 장에만 적습니다.
  - 결과 기록의 `augment`에 툴·표정·강도·툴 프롬프트와, 여러 장이면 순서(`part`/`parts`)를 남깁니다.
- **값의 근거:** 표정 24가지와 강도 6단계(defry 0~5)는 ComfyUI_NAIDGenerator가 NovelAI 웹에서 옮긴 목록과
  같습니다. 그 코드는 1024×1024 면적을 넘는 입력만 64 배수로 줄이고 나머지는 원래 크기 그대로 보냅니다. 앱도 같게
  하고(`freeAugmentSize`), 넘는 결과는 창에서 기본으로 줄여 보냅니다.
- **디렉터 툴 창**(`DirectorToolDialog`): 결과 막대·이미지 우클릭·씬 카드 메뉴·고른 카드 막대에서 엽니다.
  Emotion·배경 제거·Declutter가 위에, Line Art·Sketch·Colorize가 「더 보기」에 있습니다. 예상 Anlas를 보여 주고,
  배경 제거는 경고 상자를 띄웁니다. 큐에 넣을 때 메인 프로세스의 비용 확인 창도 그대로 뜹니다.
- **배경 제거 세 장:** 무엇이 다른지 몰라 셋 다 같은 씬에 결과로 저장합니다. 실측 뒤 필요 없는 것을 뺄지
  정합니다. 투명한 결과는 화면에서 체크무늬 위에 보입니다.
- **Emotion 툴로 씬 세트 만들기**(`SceneSetDialog`, 메뉴 「이 이미지로 씬 표정 만들기」): 씬 카드 메뉴와 디렉터
  툴 창의 Emotion에서 엽니다. 씬마다 체크·표정·강도를 고르고 결과는 각 씬에 쌓입니다.
  - 씬 항목에 `augmentMood`, `augmentDefry`를 선택 값으로 넣었습니다. 라이브러리 씬 모음 편집기의 「Emotion 툴
    표정」 카드에서 고치고, 비어 있으면 씬 이름으로 추천합니다(`suggestMood`).
  - 표정이 없는 씬과 이미지가 속한 씬은 처음에 체크하지 않습니다. 창에서 고른 값은 씬 모음에 저장합니다.

### 실측 (사용자 실행)

`legacy/tools/nai-exp/`의 계획 두 개를 따로 연 PowerShell 창에서 실행합니다.

- `planS5free.json`(무료, 허용 차감 0): 같은 입력에 Emotion 두 번(결과가 같은지), 600×900·517×771(64 배수가
  아닌 크기), 1024×1024, 517×771 Declutter.
- `planS5paid.json`(**유료, 1회**): 608×832 배경 제거. 크기별 비용과 세 장이 무엇인지 확인합니다.

(실측 결과는 여기에 적습니다.)
