# 실험 도구: NovelAI 실제 호출

실제 NovelAI 요청으로 확인해야 할 때만 읽습니다.

## 실행 규칙

- Opus 무료 범위(1024×1024 이하, 28스텝 이하, 1장)에서만 보냅니다. 유료일 수 있는 기능은 사용자에게 목록을
  보여 허락을 받은 뒤 **한 장씩만** 보냅니다. Anlas 중단 검사는 사후 검사라 한 번의 요청 비용은 막지 못합니다.
- **Claude는 실행하지 않습니다.** 자동 모드에서 실제 호출이 막힙니다. Claude는 계획 파일을 만들고 명령을
  알려 주고, 사용자가 **따로 연 PowerShell 창**에서 실행합니다(VS Code 내장 터미널에서는 실패했습니다).
- 결과 폴더는 `ForTest/` 아래에 둡니다(git 무시).

## 파일

`legacy/tools/nai-exp/`에 있습니다(git에 올라가지 않는 폴더). 앱의 프롬프트 합성·요청 생성·호출 코드를
그대로 쓰는 Electron 스크립트입니다.

- `entry.ts`: 인페인트 실험 본체. 2단계의 작업 기반 provider에 맞춰 두었습니다. 앱의 토큰 보관 파일 두 개
  (`%APPDATA%\NAI RICE\Local State`, `novelai-token.vault`)를 임시 userData로 복사해 토큰을 읽고, 끝나면 사본을
  지웁니다.
  - Opus(tier 3)가 아니면 중단합니다.
  - 생성마다 Anlas를 다시 조회해 **줄어들면 바로 중단**합니다.
  - 1024×1024 초과나 28스텝 초과 조건은 시작 전에 막습니다.
- 계획 파일(JSON): `referenceImage`, `presetFile`(프리셋 내보내기 파일), `baseLayout`, `characterId`,
  `promptSetId`, `emotionSetId`, `emotionName`, `seeds`,
  `conditions[{name, commonPositive, layout, model, generation}]`, `out`. 예시는 `planVS.json`, `planI3.json`, 생성 스크립트는 `mkv5.cjs`, `mkI.cjs`입니다.
- `probe.ts`: 인페인트가 아닌 요청(일반 생성, i2i, 디렉터 툴, 바이브 등)을 보내는 0단계 스크립트. 계획 파일은
  `planS0a~d.json`, 실행은 `run-probe.sh <계획>`입니다. 요청마다 요청 모양(이미지는 해시), 응답, Anlas·V5
  할당량 변화를 `<out>/<이름>.json`에 남기고, 차감이 허용치(30)를 넘으면 멈춥니다.
- 5단계 계획(실행 끝): `planS5free.json`(Emotion 두 번 같은 입력, 64 배수가 아닌 크기, 1024×1024, Declutter. 모두 무료이고
  허용 차감 0), `planS5paid.json`(608×832 배경 제거 1회, 허용 70). 결과는 `ForTest/stage5-free`, `stage5-paid`.
- 비교표: `sheet3.cjs <결과 폴더> <참고 그림> <seed,seed,seed> <조건,조건,...>` (환경 변수 `EXP_PROJECT`).

## 실행 방법

사용자가 PowerShell에서 실행할 때는 Git Bash 경로를 적습니다. 그냥 `bash`라고 치면 WSL의 bash가 실행되어
배포를 설치하라는 오류가 납니다.

```powershell
cd C:\Users\bobow\Desktop\risu\reference-inpaint-desk
& "C:\Program Files\Git\bin\bash.exe" legacy/tools/nai-exp/run-probe.sh <계획.json>
```

인페인트 실험(`entry.ts`)은 Git Bash에서 다음처럼 실행합니다.

```sh
P=C:/Users/bobow/Desktop/risu/reference-inpaint-desk
cd <스크립트를 둔 임시 폴더>
$P/node_modules/.bin/esbuild entry.ts --bundle --platform=node --format=cjs \
  --external:electron --alias:P=$P --outfile=entry.cjs
unset ELECTRON_RUN_AS_NODE
EXP_PROJECT=$P EXP_PLAN=<계획.json> $P/node_modules/electron/dist/electron.exe entry.cjs
```
