클짱이 힘써줬습니다.

# 인페인트 그림체 실험

레퍼런스 인셋(참고 그림을 캔버스 한쪽에 붙이고 빈 칸을 인페인트하는 방식)에서 그림체가 언제 흔들리고
무엇이 결과를 정하는지 확인한 기록입니다. 2026-10-08에 NovelAI V4.5와 V5 인페인트 모델로, 그림체 세
가지(V4.5용 2개, V5용 1개)를 같은 조건표에 넣어 비교했습니다.

## 요약

### 먼저 이렇게 두세요

참고 그림이 세로 832×1216일 때 세 장 모두 한 명이 원본 그림체로 나온 배치입니다.

| 모델 | 배치                                      | 비고                                                            |
| ---- | ----------------------------------------- | --------------------------------------------------------------- |
| V4.5 | 1216×832 · 왼쪽 · 참고 영역 47%           | 캐릭터가 가장 큼. 흰 배경 그림은 의상 태그를 직접 적어야 안정적 |
| V4.5 | 832×1216 · 위 · 전체 보이기 · 50%         | 두 그림체 모두 성공. V5에서는 실패                              |
| V5   | 1216×832 · 왼쪽 · 47%, 작가 태그 3개 이하 | 작가 태그가 16개면 3장 중 1장이 얼굴 시트                       |
| V5   | 1024×1024 · 왼쪽 · 전체 보이기 · 35%      | 캐릭터가 1024px 높이로 가장 큼                                  |

### 무엇이 결과를 정하나

- **그림체는 참고 그림이 정합니다.** 프롬프트로 다른 그림체를 만들려고 해도 결과는 참고 그림을
  따라갑니다. 작가 태그 가중치를 3까지 올리면 색이 조금 움직이지만, 그보다 먼저 구도가 깨집니다.
- **모델은 참고 그림과 같은 크기로 그리고, 남는 공간을 다른 것으로 채웁니다.** 그래서 생성 칸에 참고
  그림 크기의 그림이 딱 하나 들어가게 두는 것이 핵심입니다. 남는 공간을 V4.5는 복제와 얼굴 컷으로,
  V5는 썸네일 격자, 웹페이지·채팅 화면, 글자로 채웁니다. 폭이 좁고 세로로 긴 칸(가로:세로 1:2 이상)은
  두 모델 모두 얼굴 아이콘 시트가 됩니다.
- **참고 그림이 작게 그려지면 V4.5는 그림체가 흔들립니다.** 작가 태그가 많을수록 심해서, 20개가 넘으면
  47%에서만 원본 그림체가 나왔고 3개 이하이면 25%에서도 유지됐습니다. V5는 그림체가 거의 흔들리지 않고
  구도만 무너졌습니다. 다만 V5에서도 작가 태그가 많을수록 구도가 더 자주 무너졌습니다.
- **흰 배경 참고 그림은 칸 테두리가 보이지 않습니다.** 생성 칸 모양에 맞춰 그려서, 세로로 긴 칸에는 한
  명, 가로로 넓은 칸에는 두 명을 그립니다. 상반신만 위에 두면 그 아래 몸을 이어 그립니다.
- **V4.5에서 찾은 배치가 V5에서도 통하지는 않습니다.** V4.5에서 가장 안정적이던 세로 캔버스 위 배치는
  V5에서 세 장 모두 실패했습니다.

### 해 봤지만 해결책이 아니었던 것

- **꽉 채우기:** 캐릭터가 크게 들어가 그림체는 지키지만, 좁은 참고 영역에서는 거의 매번 여러 칸으로
  복제됩니다. 45~50%에서는 전체 보이기와 차이가 거의 없습니다.
- **작가 태그 가중치 올리기:** 색만 조금 바뀌고 구도가 먼저 깨집니다.
- **`reference inset` 태그 켜고 끄기:** 일관된 효과가 없었습니다. 앱 기본값(켜기)을 바꿀 근거는 없습니다.
- **`split screen`, `2koma`:** 참고 영역 크기를 대신하지 못합니다. 47%에서는 태그와 관계없이 성공했고,
  35%에서는 그림체에 따라 달랐습니다. `split screen`은 흰 배경 그림의 두 명 그리기를 줄이는 대신 배경
  장면을 그렸고, `2koma`는 V5 35%에서만 확실히 나았습니다.

### 피해야 할 태그

- **포지티브 안의 강한 음수 가중치와 강조된 색 태그**(`1.5::pastel colors::`와 `-3::...::` 등)가 겹치면,
  생성 칸이 좁을 때 빈 종이나 글자 문서가 나옵니다.

## 실험 방법

앱의 프롬프트 합성, 요청 생성, NovelAI 호출 코드를 그대로 쓰는 별도 스크립트로 생성했습니다. 조건마다
하나만 바꾸고 같은 시드 세 개로 생성해 비교했습니다. 같은 조건을 다시 생성하면 같은 그림이 나오는 것도
확인했습니다.

| 항목            | 값                                                                                                                                                                             |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 모델            | `nai-diffusion-4-5-full-inpainting`. 실험 V는 `nai-diffusion-5-full-inpainting`                                                                                                |
| 캔버스          | 1216×832, 참고 그림 왼쪽, 전체 보이기(contain), 위쪽 정렬, 흰 여백. 실험 C는 꽉 채우기(cover), 실험 S는 정사각·세로 캔버스                                                     |
| 생성            | 28스텝, `k_euler_ancestral`, 인페인트 강도 1, 보호 영역 확장 8px. 실험 V는 프리셋대로 23스텝, karras                                                                           |
| 캐릭터 프롬프트 | `girl, solo, 0.6::dynamic angle::, cowboy shot, medium breasts, platinum blonde hair, purple eyes, purple hair ribbon, star hair ornament`. 실험 V는 아래 3번 그림체 설명 참고 |
| 감정            | 중립 (`neutral expression, closed mouth`)                                                                                                                                      |
| 비용            | Opus 무료 범위. 모든 생성에서 Anlas 변화 없음                                                                                                                                  |

참고 그림은 두 가지입니다. 둘 다 메인 V4.5 모델로 만든 832×1216 그림입니다.

|        | 1번 그림체                               | 2번 그림체                                     |
| ------ | ---------------------------------------- | ---------------------------------------------- |
| 모습   | 짙은 남색 배경, 붓 터치가 살아 있는 채색 | 흰 배경, 파스텔, 얇은 선                       |
| 프리셋 | `테스트` (작가 태그 20개 이상, CFG 7)    | `v4.5` (작가 태그 7개, CFG 7, CFG rescale 0.4) |

"작가 3개"는 작가 태그를 세 개만 남긴 것이고, "작가 없음"은 작가 태그를 모두 뺀 것입니다. 나머지
태그는 그대로 두었습니다. 작가 태그 목록은 문서에 싣지 않았습니다.

## 실험 1: 1번 그림체에서 무엇이 그림체를 흔드나

지금 쓰는 설정(참고 영역 30%)을 기준으로 한 가지씩 바꿨습니다.

| 조건                                | 결과                                          |
| ----------------------------------- | --------------------------------------------- |
| A 기준 (30%, 작가 20개 이상)        | ✗ 세 장 모두 그림체·포즈·배경이 제각각        |
| B 작가 3개                          | ✓ 원본에 가까움                               |
| C `animated`와 음수 가중치만 뺌     | ✗ A와 같이 흔들림. 한 장은 두 칸으로 갈라짐   |
| D 참고 영역 45% (프롬프트는 그대로) | ✓✓ 원본과 거의 같음. 표정만 프롬프트대로 바뀜 |
| E 작가 없음                         | ✓ 원본 그림체. 디테일은 D보다 조금 약함       |

## 실험 2: 같은 조건표를 2번 그림체로

| 참고 영역 | 작가 7개                                    | 작가 3개                   | 작가 없음             |
| --------- | ------------------------------------------- | -------------------------- | --------------------- |
| 25%       | 그림체 유지. 한 장은 캐릭터가 두 명         | 그림체 유지. 한 장은 두 명 | 세 장 모두 두 명      |

  나왔고, 세로로 긴 칸(672×1024)에서는 한 명이 나왔습니다.
- 캐릭터 프롬프트에 의상 태그가 없어, 참고 신호가 약할 때 의상이 바뀌었습니다.
- 빈 종이의 원인은 실험 B에서 찾았습니다.

## 실험 B: 빈 종이와 글자 문서의 원인

실험 X에서 세 장 모두 빈 종이였던 조건(참고 영역 47%, 2번 프리셋, 작가 없음)에서 후보를 하나씩 뺐습니다.

| 뺀 것                                                                                                              | 결과 (3장)                                          |
| ------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------- |
| (없음, 대조군)                                                                                                     | ✗ 이전과 똑같은 빈 종이 3장                         |
| `1.5::pastel colors::`                                                                                             | ✓ 세 장 모두 정상. 참고 그림도 가장 충실하게 따라감 |
| 음수 가중치 묶음 (`-1::flat color::`, `-3::multiple views::`, `-3::thick lineart::`, `-3::artist collaboration::`) | ✓ 세 장 모두 정상                                   |
| `novel illustration`                                                                                               | △ 1장 정상, 나머지는 장식 글자와 얼굴 시트          |
| `official art`                                                                                                     | △ 1장 정상, 나머지는 글자 문서와 얼굴 시트          |
| `-1::clean text::`                                                                                                 | ✗ 세 장 모두 글자 문서로 바뀜                       |
| `solo artist`                                                                                                      | ✗ 빈 종이 3장                                       |
| reference inset을 맨 끝에서 맨 앞으로                                                                              | ✗ 글자 문서와 얼굴 시트                             |

- 파스텔을 1.5배로 강조하고 선과 단색 채색을 음수 가중치로 누르니, 좁은 칸에서 모델이 "옅고 선 없는
  그림", 곧 하얀 종이로 결론 낸 것으로 보입니다. 둘 중 하나만 빼도 해결됐습니다.
- 빈 종이와 글자 문서는 같은 현상입니다. `-1::clean text::`가 글자를 누르고 있어서 빈 종이였고, 그
  태그를 빼자 글자가 나타났습니다.
- 작가 태그가 있으면 그림 쪽 신호가 강해 이 현상이 나오지 않았습니다.

## 실험 C: 꽉 채우기

인페인트 설정의 "꽉 채우기"(cover)는 참고 그림을 칸 높이에 맞춰 키우고 넘치는 양옆을 잘라 냅니다.
세로 그림을 좁은 칸에 넣으면 참고 영역 25%에서 폭 304px, 35%에서 424px의 세로 띠가 됩니다. 실험 1b,
실험 2와 프리셋·조건표·시드를 같게 두고 배치 방식만 바꿨습니다.

![꽉 채우기 캔버스 (위: 1번, 아래: 2번 / 왼쪽부터 25%, 35%, 47%)](인페인트-실험/10-실험C-꽉채우기-캔버스.jpg)

| 참고 영역 | 1번 그림체 (작가 20개 이상)                  | 2번 그림체 (작가 7개)                        |
| --------- | -------------------------------------------- | -------------------------------------------- |
| 25%       | 그림체는 유지. 대신 거의 모두 2~6칸으로 복제 | 거의 모두 2~3명이 나란히                     |
| 35%       | 그림체 유지. 9장 중 6장이 2칸 복제           | 거의 모두 2명                                |
| 47%       | ✓ 한 명, 원본 그림체                         | 전체 보이기와 같은 결과 (의상 변화, 빈 종이) |

- 작가 태그 20개 이상인 1번 그림체도 25%에서 그림체가 흔들리지 않았습니다. 같은 조건을 전체 보이기로
  넣었을 때는 콜라주로 무너졌습니다. 그림체를 정하는 것은 캐릭터가 그려진 크기입니다.
- 대신 모델이 캔버스를 여러 칸짜리 시트로 보고, 참고 칸과 같은 폭의 칸을 생성 영역에 반복해 채웠습니다.
  304px 띠 옆에 912px 생성 칸을 두면 띠가 2~3개 더 그려집니다. 생성 칸(648px)이 참고 칸(568px)과
  비슷한 47%에서만 한 명이 나왔습니다.
- 47%에서는 원래 그림이 칸에 꽉 차서 두 방식의 캔버스가 같고, 결과도 전체 보이기 때와 같은 그림이
  나왔습니다.

## 실험 I: reference inset 태그, split screen, 2koma

지금까지의 실험은 모두 앱 기본값대로 `reference inset` 태그를 넣은 상태였습니다. 이 태그를 빼거나,
커뮤니티에서 쓰는 `split screen`, `2koma`를 포지티브 맨 앞에 넣어 비교했습니다. 세 그림체 모두 작가
태그 전체, 1216×832 · 왼쪽 · 전체 보이기에서 참고 영역 35%와 47%를 썼습니다.

| 조건           | 프롬프트                                                                    |
| -------------- | --------------------------------------------------------------------------- |
| inset (대조군) | 앱 기본값. `reference inset`을 프리셋 위치(1번·3번 맨 앞, 2번 맨 끝)에 넣음 |
| 끔             | `reference inset` 없음                                                      |
| split          | `reference inset` 없이 `split screen`                                       |
| 2koma          | `reference inset` 없이 `2koma`                                              |
| inset + split  | `reference inset, split screen`                                             |

대조군은 실험 1b, 실험 2, 실험 V1b의 같은 조건과 픽셀까지 같은 그림이 나왔습니다. 프롬프트를 한
단어만 바꿔도 같은 시드에서 다른 그림이 나오므로, 세 장 중 한 장 차이는 우연일 수 있습니다.

## V5 관찰 (통제하지 않은 결과)

V5 인페인트 모델(`nai-diffusion-5-full-inpainting`)로 앱에서 뽑은 이미르 결과 32장입니다. 감정, 시드,
스텝이 섞여 있어 조건별 비교는 할 수 없습니다.

- 원본이 정사각형(1024×1024)이라 좁은 참고 칸에 넣으면 아주 작아졌습니다. 참고 영역 25%에서는
  304×304, 35%에서는 424×424로 그려졌고, 아래는 흰 여백이었습니다.
- 의상 구성, 투톤 머리색, 비녀는 대부분 유지됐습니다.
- 머리색이 밝은 하늘색으로 바뀌거나, 광택이 많은 채색, 체형 과장, 치마색 변경이 일부 나왔습니다.

참고 그림이 작아서라는 V4.5의 결과와 맞는 모습입니다. 같은 조건표로 비교한 결과는 실험 V에 있습니다.

## 실전 정리

| 상황                                | 하면 좋은 것                                                                                                                                                                        |
| ----------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 원본 그림체를 지키고 싶다           | 생성 칸에 참고 그림 크기의 그림이 하나 들어가게 둡니다. 세로 832×1216 그림이면 1216×832·왼쪽·47%(캐릭터가 가장 큼) 또는 832×1216·위·전체 보이기·50%(V4.5에서 가장 안정적)입니다     |
| 캐릭터가 여러 명·여러 칸으로 나온다 | 참고 영역을 넓혀 생성 칸을 참고 그림 크기에 가깝게 줄입니다                                                                                                                         |
| 얼굴 아이콘만 잔뜩 나온다           | 생성 칸이 폭이 좁고 세로로 긴(1:2 이상) 모양입니다. 참고 영역을 줄이거나 캔버스를 바꿉니다                                                                                          |
| 흰 배경 참고 그림을 쓴다            | 참고 그림을 위에 두고 꽉 채우기로 상반신만 넣지 않습니다. 아랫몸을 이어 그립니다                                                                                                    |
| 결과 칸을 넓게 쓰고 싶다            | 권하지 않습니다. 작가 태그를 3개 이하로 줄이면 그림체는 지켜지지만, 흰 배경 그림이면 여러 명이 나오기 쉽습니다                                                                      |
| 꽉 채우기를 쓸까                    | 45~50%에서는 전체 보이기와 차이가 거의 없습니다. 좁은 참고 영역에서 쓰면 여러 칸으로 복제됩니다                                                                                     |
| 빈 종이나 글자 문서가 나온다        | 포지티브의 강한 음수 가중치(`-3::`)와 강조된 색 태그를 줄이거나 네거티브로 옮깁니다                                                                                                 |
| 의상이 바뀐다                       | 의상 태그를 캐릭터 프롬프트에 직접 적습니다                                                                                                                                         |
| V5를 쓴다                           | 1216×832·왼쪽·47%에 작가 태그 3개 이하, 또는 1024×1024·왼쪽·35%입니다. 세로 캔버스 위 배치는 V5에서 실패했습니다                                                                    |
| split screen·2koma를 넣을까         | 참고 영역이 충분하면 필요 없습니다. 좁은 영역에서 흰 배경 그림이 두 명으로 나오면 `split screen`을, V5면 `2koma`를 시도해 볼 만합니다. `split screen`은 배경 장면을 그리기 쉽습니다 |
| 다른 그림체로 만들고 싶다           | 메인 모델로 그 그림체의 참고 그림을 새로 만듭니다. 프롬프트만으로는 바뀌지 않습니다                                                                                                 |

## 한계

- V5는 실험 V(흰 배경의 3번 그림체 하나)만 했습니다. 3번 그림체를 V4.5로는 돌리지 않아, V4.5와의
  차이가 모델 때문인지 그림체 때문인지 완전히 가를 수는 없습니다. 짙은 배경 그림은 V5로 실험하지
  않았습니다.
- 그림체마다 캐릭터 하나, 감정 하나(중립), 조건마다 시드 세 개입니다. V5에서 표정 프롬프트가 참고
  그림의 표정을 얼마나 바꾸는지는 확인하지 않았습니다.
- 결과는 눈으로 비교해 판단했습니다.
- CFG를 낮추면 참고 그림을 더 따라가는지, 참고 칸과 생성 칸 사이에 경계를 표시하면 여러 명 그리기가
  줄어드는지는 아직 확인하지 않았습니다.
- 참고 그림은 세 장 모두 세로 832×1216이었습니다. 정사각형이나 가로 참고 그림은 실험하지 않았습니다.
