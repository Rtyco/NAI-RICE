# NAI RICE 자세한 설명

짧은 소개와 받는 곳은 [README](../README.md)에 있습니다.

NovelAI 인페인팅(공식 문서의 Reference Inpainting 기법)으로 캐릭터 감정 이미지 세트를 만드는 Windows 데스크톱 프로그램입니다.
캐릭터 참고 이미지를 빈 생성 영역 옆에 놓으면 NovelAI가 그 영역에 같은 캐릭터를 감정별로
그립니다. 결과는 잘라서 감정마다 저장합니다.

NovelAI와 관련이 없는 비공식 프로그램입니다. NAI RICE는 [SD Studio](https://github.com/sunho/SDStudio)(원작 sunho, [현행 Dd154663](https://github.com/Dd154663/SDStudio))에서 파생된 프로젝트입니다. 출처와 사용한
오픈소스 라이브러리의 라이선스는 [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md)에, 변경 내역은
[CHANGELOG.md](../CHANGELOG.md)에 있습니다.

## 구성

다시 쓸 수 있는 네 가지 라이브러리 항목을 **작업**이 하나씩 골라 조합합니다.

```text
생성 설정  +  캐릭터 (+ 프롬프트 세트)  +  감정 모음  +  인페인트
```

- **생성 설정**(코드에서는 `presets`): 상위·하위 프롬프트(씬 프롬프트가 그 사이에 들어감), 공통 네거티브, 모델(V5, V4.5
  Full/Curated, V4 Full/Curated, Anime/Furry V3), 샘플러, 스텝, 가이던스, 시드 규칙, NovelAI 품질
  태그(V5는 Standard 또는 Light), UC 프리셋.
- **추가 프롬프트**: 작업마다 하나. 상위 프롬프트 바로 뒤에 붙고 생성 설정에는 저장하지 않습니다. 프롬프트
  패널에서 접어 두며, 접혀 있어도 내용이 있으면 「작성됨」이 보입니다.
- **캐릭터**: 캐릭터 프롬프트 세트(예: 의상마다 하나).
- **감정 모음**: 감정 이름과 프롬프트. 여러 작업에서 함께 씁니다.
  - 조합 칸(SD Studio 프롬프트 조합): 칸마다 후보를 여러 개 두고 켜고 끕니다. 씬을 생성하면 칸마다 켜진
    후보 하나씩 고른 모든 조합을 만들고, 결과 정보에 고른 후보가 남습니다. 후보는 씬 프롬프트 자리 몫과
    캐릭터마다의 몫을 따로 가집니다. 작업의 캐릭터보다 많이 늘린 캐릭터 몫 칸은 「－ 캐릭터」로 마지막 칸부터
    지웁니다. 켜진 후보가 없는 칸이 있으면 그 씬은 생성되지 않습니다.
    맨 위에 조합 수와 칸마다 켜진 후보 수의 곱(예: 「조합 4개 = 2 × 2」)이 보이고, 그 아래 칸 번호 탭(옆 숫자는
    켜진 후보 수)으로 칸을 하나씩 엽니다. 씬 상세 오른쪽 패널에서는 후보를 하나씩 펼치고 접으며(↑↓로 후보 이동),
    칸을 열면 첫 후보가 펼쳐져 있습니다(설정 › 화면·테마에서 모두 펼침·모두 접음으로 바꿀 수 있음). 칸 머리의
    「모두 펴기」「모두 접기」로 한꺼번에 바꿉니다. 접힌 후보는 이름과 프롬프트 앞부분 한 줄로 보입니다. 라이브러리 씬 모음에서는 후보가 표의 한 줄이고 씬
    자리와 캐릭터 몫이 열입니다. 씬 상세 오른쪽 패널은 「씬 프롬프트」와 「조합 프롬프트」 단추로 둘 중 하나를
    보여 주고, 씬을 넘겨도 고른 쪽이 유지됩니다.
  - 씬 프롬프트와 조합 칸: 조합 칸이 있으면 씬 프롬프트는 모든 조합에 공통으로 들어가고(「모든 조합 공통」),
    고른 후보가 그 뒤에 칸 순서대로 붙습니다. 같은 태그를 양쪽에 쓰면 두 번 들어갑니다. 씬 프롬프트와
    후보 칸 아래에 한 조합에서 함께 붙는 칸끼리 겹친 태그가 「겹치는 태그 …」로 표시되고(같은 칸의 후보끼리는
    함께 붙지 않아 세지 않습니다), 최종 요청 미리보기에서는 캐릭터·생성 설정 프롬프트까지 합친 결과에서 겹친
    태그가 칠해집니다. 다른 프롬프트 칸은 그 칸 안에서 겹친 태그를 표시합니다(여러 줄 조각은 제외).
    「씬 프롬프트 → 칸 1」(조합 칸이 없을 때도 보입니다)은 씬 프롬프트를 후보 하나짜리 첫 칸으로 옮기고,
    「씬 프롬프트로 합치기」는 후보가 하나뿐인 첫 칸을 씬 프롬프트에 합칩니다. 어느 쪽도 만들어지는 프롬프트는
    같습니다. SD Studio에서 가져온 씬은 내용이 모두 조합 칸에 있습니다.
  - 결과의 「프롬프트 복원」은 씬 프롬프트와 그 결과에 쓰인 후보의 내용을 생성 당시로 되돌립니다. 그 사이 지운
    후보는 되돌리지 않습니다. 1.1.2 이전 결과는 씬 프롬프트와 씬 네거티브만 되돌립니다.
  - 씬 seed와 씬 크기: 비우면 생성 설정을 따릅니다. 씬 크기는 일반 생성에서만 쓰고, 인페인트는 캔버스
    크기, 씬 i2i는 이미지 크기를 씁니다.
- **인페인트**: 캐릭터 참고 이미지와 마스크, 결과 영역.
  - 캔버스: 자동 구성(1216×832, 832×1216, 1024×1024 또는 64의 배수 커스텀 크기)이나 직접 준비한
    캔버스. 자동 구성에서는 참고 영역 안에서 이미지를 전체 보이기나 꽉 채우기로 상단, 중앙, 하단에
    맞추거나, 「자유 배치」로 위치, 크기, 회전, 좌우 반전을 직접 정합니다. 캔버스에서
    Ctrl+T(이미지 변형)를 누르면 포토샵의 자유 변형처럼 끌어서 옮기고 크기를 바꾸고 돌립니다.
  - 분리선: 생성 영역 경계를 따라 선을 그어 결과 쪽이 따로 나뉜 칸임을 알립니다. 색, 두께(8px
    단위), 위치(생성 영역 바깥·경계에 걸침·생성 영역 안쪽), 경계와의 간격을 고릅니다. 바깥에 두면
    NovelAI가 다시 그리지 않아 그대로 남고, 안쪽에 두면 덮어 그려질 수 있습니다.
  - 그리기: i2i 그리기와 같은 도구로 캔버스에 덧칠합니다. 그린 것은 따로 저장되어 배치를 바꿔도
    남고, NovelAI에 보내는 캔버스에 합쳐집니다.
  - 생성: 인페인트 강도. 이 인페인트를 쓰는 작업은 생성 설정의 값 대신 이 값을 씁니다.
  - 자유 생성: i2i 이미지 칸의 「인페인트에서 불러오기」로 캔버스와 마스크, 결과 영역, 강도를 복사해 옵니다.
    인페인팅으로 생성하면 작업처럼 reference inset이 붙고 결과 영역만 남습니다. 복사본이라 자유 생성에서
    마스크나 강도를 바꿔도 라이브러리의 인페인트는 그대로입니다.
- **캐릭터 레퍼런스·바이브로 보내기**: 결과 이미지 우클릭(씬 카드는 대표 이미지)의 「캐릭터 레퍼런스로
  보내기」·「바이브로 보내기」는 그 이미지로 새 항목을 만들어 그 작업(자유 생성 결과는 자유 생성)의 참고에
  넣습니다. 캐릭터 레퍼런스는 고른 것을 바꾸고, 바이브는 고른 것 뒤에 더합니다.
- **프롬프트 조각**: 어느 프롬프트에서든 `<세트.조각>`으로 부르는 재사용 문구입니다(SD Studio
  문법). 여러 줄 조각은 이미지마다 시드에 따라 한 줄을 고릅니다. SD Studio 조각 파일과 SD Studio
  프로젝트 안의 조각 라이브러리를 바로 가져올 수 있습니다.
- **SD Studio 문법**: `##메모##`는 보내기 전에 지웁니다(여러 줄도 됩니다). `{jeans|black pants}`처럼
  중괄호 안에 `|`를 쓰면 후보 하나를 시드에 따라 고릅니다. `|`가 없는 중괄호는 NovelAI 강조 그대로입니다.
- **작업**: 위 항목을 하나씩 골라 자유롭게 바꿔 조합합니다. 생성 결과, 대표 이미지, 작업별 제외
  감정은 작업에 속합니다.

### 화면

- **감정 갤러리**: 감정마다 대표 이미지나 최신 결과를 보여 줍니다. 카드를 우클릭하면 이름 변경,
  복제, 프롬프트 복사, 결과 폴더 열기, 삭제를 할 수 있습니다. 씬 상세에 들어갔다 나오면 보던 자리로
  돌아오고, 방금 본 씬 카드가 잠깐 강조됩니다. 위의 도구 줄(모두 고르기, 씬 이름 검색, 내보내기, 보기)은
  내려도 화면 위에 남습니다.
- **씬 상세 모아 보기**: 결과를 한 장씩 크게 보는 대신 그 씬의 결과를 원본 그대로(잘리지 않게) 여러 장 모아
  봅니다. 결과 화면 오른쪽 위 버튼이나 G 키로 오가고, 한 줄에 보일 장수(2~6)를 고릅니다. 두 번 클릭하거나
  Enter를 누르면 그 결과를 한 장으로 봅니다. 우클릭 메뉴, 여러 장 고르기, 결과 막대는 한 장씩 볼 때와 같습니다.
- **생성할 씬 체크**: 카드의 체크가 켜진 씬만 아래 생성 버튼으로 한꺼번에 생성합니다. 체크를 하나 누른 뒤 다른
  카드의 체크를 Shift+클릭하면 그 사이 씬이 모두 같은 상태가 됩니다. 카드를 여러 개 고르면 위 도구 줄의
  「생성 포함」·「생성 제외」로 고른 씬의 체크를 한꺼번에 바꿉니다.
- **이미지 내보내기**(Ctrl+E): 씬마다 대표 한 장, 조합마다 한 장, 모든 생성 이미지 중에서 골라 폴더나 ZIP으로
  내보냅니다. 조합마다·모든 이미지로 내보낼 때 파일 이름에 `{combo}`(조합 이름)나 `{comboNumber}`(씬 안
  조합 순서, 예: `기쁨_01`)가 없으면 조합 이름을 뒤에 붙입니다. 조합 순서는 씬의 지금 조합 순서이고, 후보를
  지운 조합의 결과는 그 뒤 번호입니다.
- **다듬기**: 결과를 고른 크기로 다시 그립니다. 모델(원본과 같게 또는 직접 고르기)과 프롬프트도 고를 수
  있고, 마지막에 쓴 값은 작업에 저장됩니다. 프롬프트는 원본 그대로, 네거티브만 남기기, 비우기(네거티브도),
  직접 입력 중에 고릅니다. 원본 말고는 캐릭터 프롬프트를 보내지 않고, 직접 입력은 쓴 그대로 보냅니다(조각과
  품질 태그를 붙이지 않습니다).
- **씬 i2i**: 씬 상세 오른쪽 패널 맨 위에서 「프롬프트 생성」(작업의 생성 방식인 인페인트·일반 생성)와 i2i를 고릅니다. i2i는 자유
  생성의 i2i와 같아서 이미지를 파일·인페인트에서 불러오거나, 전체 다시 그리기·인페인팅(마스크 칠하기)·그리기를
  쓰고 강도와 노이즈는 생성 설정에 저장됩니다. 프롬프트는 그 씬의 프롬프트(조합 포함)를 쓰고 결과는 그 씬에
  쌓입니다. 결과 막대와 이미지 우클릭의 「이 결과로 i2i」, 갤러리 씬 카드 우클릭의 「이 이미지로 i2i」(대표 이미지,
  없으면 최신)는 그 이미지를 넣고 i2i를 켭니다. 이미지와 켜짐 여부는 씬마다 작업에 저장되며, 작업 내보내기와
  가져오기에는 들어가지 않습니다.
- **구분선 지우기**: 인페인트 결과를 잘라 낸 뒤에도 가장자리에 남는 검은 구분선(NovelAI가 생성 영역 안에 다시
  그린 선)을 찾아 그 자리만 인페인트합니다. 결과의 네 가장자리에서 48px 안에서 시작해 위아래(또는 양옆)
  끝까지 이어진 두께 96px 이하의 어두운 띠를 찾고, 양옆에 여유를 더해 NovelAI 마스크 칸(8px)에 맞춰 칠합니다.
  - 결과를 i2i로 보내면(「이 결과로 i2i」, 「자유 생성으로 보내기」, 파일에서 불러오기) 구분선을 찾아 인페인팅을
    켜고 마스크를 칠해 둡니다. 마스크는 붓과 지우개로 고칠 수 있고, i2i 이미지 칸의 「구분선 찾기」로 다시 찾을
    수 있습니다(칠해 둔 마스크에 더합니다).
  - 결과 막대·이미지 우클릭·씬 카드 우클릭·고른 카드 도구 줄의 「구분선 지우기」는 다듬기처럼 창에서 모델(원본과
    같게 또는 인페인트 모델), 프롬프트, 세기, 마스크 여유, 장수, seed를 골라 바로 생성 큐에 넣습니다. 결과는 원래
    크기로 잘려 그 씬에 쌓이고, 구분선을 찾지 못한 결과는 뺍니다. 값과 자동 찾기 켜짐은 프로그램 설정에
    저장됩니다. V5 Curated처럼 인페인트 모델이 없는 모델은 고를 수 없습니다.
  - 인페인트 모드 작업은 설정 줄의 「자동 후처리」 칩이나 씬 상세 생성 버튼 위의 「자동 구분선 지우기」로 켜면
    결과가 나올 때마다 구분선을 찾아, 찾은 결과만 설정한 장수만큼 지웁니다(기본 1장). 켜짐은 작업에, 값은
    프로그램 설정에 저장되며, 생성 버튼과 예상 Anlas에는 최대치가 더해집니다.
- **자동 다듬기**: 설정 줄의 「자동 후처리」 칩(자유 생성은 「자동 다듬기」 칩)이나 씬 상세의 생성 버튼 위에서
  켜면 씬을 생성할 때 결과가 나올 때마다 바로 이어서 다듬습니다. 자동 구분선 지우기도 켜 두면 구분선을 지운
  결과를 다듬습니다. 다듬기 창에서도 켤 수 있습니다. 칩과 생성 버튼 위의 연필로 다듬기 값을 바꾸며, 생성 버튼과 예상 Anlas에 다듬기 장수가 더해집니다. 대표 이미지를 고르지 않은 씬은 카드에
  다듬은 결과가 보입니다. 칩에는 모델 약칭(원본과 같으면 생략)과 세기, 프롬프트 방식 아이콘이 보입니다.
  자유 생성에도 같은 칩과 생성 버튼 위 체크가 있고 값은 자유 생성에 따로 저장됩니다(디렉터 툴 결과는 다듬지
  않습니다).
- **씬 이름 검색**: 갤러리 도구 줄에 이름 일부를 넣으면 맞는 씬만 보이고, 모두 고르기(Ctrl+A)도 보이는 씬만
  고릅니다. 씬 상세의 이전·다음(PageUp·PageDown)도 검색 결과 안에서 넘어갑니다. 검색어는 작업마다 따로이며
  프로그램을 끄면 지워집니다. 라이브러리의 씬 모음 편집에도 같은 검색 칸이 있습니다. 씬 상세의 「n / m」을 누르면 씬 목록이 떠
  갤러리로 나가지 않고 다른 씬으로 갑니다.
- **라이브러리 긴 목록**: 씬 모음, 프롬프트 조각, 캐릭터 프롬프트 세트는 내려도 머리줄(추가 버튼)이 위에
  남습니다. 추가하면 목록 끝의 새 항목으로 스크롤하고 이름 칸이 선택됩니다. 씬 모음의 씬은 펼쳐져 있고 조합 칸만
  한 줄(조합 수와 켜진 후보 이름)로 접혀 있습니다. 씬도 접을 수 있고(이름, 프롬프트 앞부분, 조합 수), 「모두 접기」로
  한꺼번에 접습니다.
- **라이브러리·작업 목록**: 끌어서 놓아 순서를 바꾸고, 두 번 클릭하거나 우클릭해 이름을 바꿉니다.

  클릭도 됩니다). 고른 항목은 Delete 키나 「삭제」 버튼으로 한꺼번에 지웁니다. 갤러리에서 고른 카드를
  우클릭하면 생성, 일괄 생성 포함·제외, 복제, 다듬기, 디렉터 툴, 삭제가 고른 씬 모두에 적용됩니다.

  넣고, `artist:`로 시작하면 작가만 찾습니다. 태그 목록이 프로그램에 들어 있어 인터넷 없이 동작합니다.

  바꾸기, F5 새로 고침, F6 이미지 목록, F7 왼쪽 패널, F8 히스토리, F9 설정 줄, F11 전체 화면, Ctrl+F 찾기, Ctrl+H 찾아
  바꾸기, Ctrl++/-/0·Ctrl+휠 확대, Ctrl+Tab 다음 작업, Ctrl+Enter 생성, 결과 이미지의 Ctrl+C 복사와 Z·Ctrl+1 확대 등.
  패널 키는 Lightroom, 그리기·마스크 키는 포토샵과 같습니다. 우클릭 메뉴는 Shift+F10이나 메뉴 키로도 열리고, 항목
  이름 뒤 글자(예: 다른 이름으로 저장 (A))를 누르면 바로 실행됩니다. 전체 목록은 프로그램 설정 › 단축키에 있습니다.

  수이고, 씬이 여럿이면 가장 긴 씬 기준입니다. 한도를 넘으면 빨갛게 바뀌고 뒤쪽이 잘립니다. NovelAI 웹과
  같은 토크나이저를 쓰며, 모델 종류마다 처음 한 번 novelai.net에서 받아 둡니다(토큰은 쓰지 않습니다).
- **히스토리**: 작업과 자유 생성 화면 오른쪽 끝에 NovelAI 웹처럼 최근 결과부터 세로로 보여 줍니다.
  누르면 그 결과를 열고(작업은 그 씬의 상세 화면), F8로 접습니다. 다른 씬 모음으로 만든 결과를 누르면 작업의 씬
  모음을 그 모음으로 바꾸고 엽니다.
- **휠 클릭 스크롤**: 히스토리, 갤러리, 목록처럼 스크롤되는 곳에서 휠을 누르면 브라우저처럼 마우스를 위아래로
  움직이는 만큼 저절로 스크롤됩니다. 다시 누르거나 Esc로 멈춥니다. 휠을 누른 채 끌었다면 놓을 때 멈춥니다.
- **사이드바·왼쪽 패널**: 사이드바는 접기 버튼을 누를 때마다 펼침 → 아이콘만 → 숨김 순으로 바뀌고(Ctrl+B),
  프롬프트 패널과 라이브러리 목록은 접기 버튼(‹)이나 F7로 펼침과 숨김만 오갑니다. 라이브러리 목록은 경계를 끌어
  최소 폭보다 더 좁히면 아이콘만 남은 모양이 됩니다. 숨긴 사이드바는 창 맨 위 줄 왼쪽 버튼으로, 숨긴 프롬프트 패널과 라이브러리 목록은 화면 머리줄 왼쪽 끝에

  아이콘(옆 숫자는 작업 수)을 눌러 접고 폅니다. 아이콘만 남은 라이브러리 목록의 폴더도 같은 방법으로 접고 폅니다. 폴더를 우클릭하면 폴더 색을 고를 수 있고,
  색은 폴더 아이콘과 펼친 폴더에 보이며 라이브러리에 저장됩니다. 창이 낮으면 라이브러리 칸이 스크롤로 줄어 작업 목록 자리를 남깁니다.
- **좁은 창**: 창이 좁거나 화면 확대 비율이 크면 패널을 알아서 접습니다. 폭 1280px(확대 비율로 나눈 값, 예:
  1920px 창의 150%) 아래에서는 히스토리를 접고 사이드바를 아이콘만 남기며, 960px(1920px 창의 200%) 아래에서는
  프롬프트 패널·라이브러리 목록도, 640px 아래에서는 입력 패널도 숨기고 사이드바는
  아이콘만 남깁니다(이 폭에서 사이드바 버튼은 아이콘만과 숨김만 오갑니다). 저장한 패널 상태는 바뀌지
  않아 창을 넓히면 돌아오고, 접힌 패널은 평소처럼 버튼으로 다시 엽니다. 960px 아래에서 다시 연 패널은 이미지 칸을

  접히고, 갤러리는 한 줄에 2장, 대화 창은 화면 전체를 씁니다. 터치 화면에서는 마우스를 올려야 보이던 편집·지우기 버튼이

  손가락이 닿으면 칠하던 획은 취소), 휴대폰 폭에서는 캔버스 도구가 아래쪽 한 줄로 옮겨 갑니다.

  넉넉하면 칩마다 아이콘·이름·고른 값이 보이고, 좁아지면 이름을 먼저 숨기고 값의 뒷부분을 줄이다가 마지막에 아이콘만
  남습니다. 값은 칩에 마우스를 올리면 나오고, 항목 편집은 칩을 눌러 연 고르기 창에서 합니다. 줄 오른쪽 끝 버튼이나 F9로

  바뀝니다. 씬 상세의 씬 이동 줄도 함께 접히고, 대신 머리줄에 갤러리·이전·다음 버튼과 몇 번째 씬인지가 남습니다.

  켜 두면, 지금 계정의 V5 무료 할당량이 바닥났을 때 V5 생성 직전에 목록 순서대로 할당량이 남은 Opus 계정을
  찾아 바꿉니다. 한 번에 한 계정만 쓰고(동시 생성 없음) 요청 간격도 그대로 지킵니다. 무료 조건(1024×1024,
  28 Steps)을 넘는 생성이나 V5가 아닌 모델은 계정을 바꾸지 않습니다. 예상 Anlas도 다른 계정에 할당량이
  남았으면 무료로 셉니다. 1.1.4 전에 저장한 토큰은 「계정 1」이 됩니다.
- **저장 공간**: 프로그램 설정 › 저장 공간 · 백업에서 작업별 용량을 보고, 대표(★) 이미지를 뺀 결과를
  한꺼번에 정리하거나 기록과 파일이 맞는지 점검합니다. 지운 결과는 Windows 휴지통으로 갑니다.
- **작업 폴더 위치**: 기본은 `문서\NAI RICE`입니다. 저장 공간 · 백업 › 작업 폴더의 「위치 바꾸기…」로 다른
  폴더나 드라이브로 옮깁니다. 지금 작업 폴더를 복사해 크기를 확인한 뒤 프로그램을 다시 시작하고, 다시 시작하면
  이전 폴더를 휴지통으로 보낼지 묻습니다(「남겨 두기」도 됩니다). 고른 폴더에 이미 `library.json`이 있으면
  복사하지 않고 그 데이터로 바꿉니다. 비어 있지 않은 폴더를 고르면 그 안에 `NAI RICE` 폴더를 만듭니다. 생성
  중에는 옮길 수 없습니다. NovelAI 토큰·생성 큐·화면 설정은 작업 폴더가 아니라 Windows 사용자 폴더(AppData)에
  있어 그대로 남습니다. 옮긴 폴더를 찾을 수 없으면(외장 드라이브를 뺀 경우 등) 시작할 때 다시 찾을지 기본
  위치로 열지 묻습니다.
- **테마**: 색 테마 다섯 가지를 다크·라이트 모드(또는 Windows 설정 따르기)로 쓸 수 있습니다. 창
  제목 표시줄도 테마를 따릅니다.

### 프롬프트 입력

프롬프트 입력란은 NovelAI V4.5/V5 문법(`{}`, `[]`, 숫자 가중치, `::`)을 색으로 구분하고, 커서 옆
괄호의 짝을 보여 줍니다. 다음 문제를 목록으로 알려 줍니다.

- 짝이 맞지 않는 괄호
- 끝나지 않은 가중치
- 없는 프롬프트 조각

긴 프롬프트는 크게 보기 창에서 편집합니다. Ctrl+Enter로 적용하고 Esc로 취소합니다.

**찾기·바꾸기**: Ctrl+F로 찾고 Ctrl+H로 바꿉니다. 찾는 범위는 세 가지입니다.

- **이 칸**: 프롬프트 칸에서 누르면 그 칸에서만 찾습니다.
- **이 항목**: 라이브러리에서 연 항목 하나(예: 씬 모음 하나), 또는 자유 생성 화면에서 찾습니다. 라이브러리
  편집 화면에서 누르면 이 범위로 열립니다.
- **라이브러리 전체**: 생성 설정, 캐릭터, 씬 모음(조합 칸 후보 포함), 프롬프트 조각, 자유 생성의 프롬프트를 모두 찾습니다.

찾은 곳은 주황색으로 칠해지고 Enter·F3으로 다음, Shift+Enter·Shift+F3으로 이전 곳으로 갑니다.

- **태그 단위**(기본으로 켜짐): 쉼표로 나뉜 태그와 통째로 같을 때만 찾습니다. `hair`는 `silver hair`나
  `hairband`에 걸리지 않습니다. 괄호·가중치 안의 태그도 찾고, 대소문자는 가리지 않습니다. 바꿀 내용을
  비우면 그 태그와 붙어 있던 쉼표를 함께 지웁니다.
- **이름만**(기본으로 꺼짐): 프롬프트 대신 이름에서 찾고 바꿉니다. 라이브러리 항목 이름과 그 안의
  프롬프트 세트·씬·조각 이름이 대상입니다. 이름은 태그 단위와 관계없이 글자가 들어 있으면 찾습니다
  (「기본」으로 「기본 씬 6종」을 찾습니다). 결과를 누르면 그 이름 칸으로 가서 찾은 글자를 고릅니다. 바꾸면
  비게 되는 이름은 그대로 두고, 조각 이름을 바꾸면 `<세트.조각>` 참조도 함께 바뀝니다.
- **생성 기록 포함**(기본으로 꺼짐, 라이브러리 전체에서만): 이미 만든 결과에 실제로 보낸 프롬프트에서도
  찾습니다. 최신 200개까지 보여 주고, 누르면 그 결과를 엽니다. 기록은 바꾸지 않습니다.
- 「이 항목」·「라이브러리 전체」 바꾸기는 몇 칸에서 몇 개를 바꾸는지 확인한 뒤 바꾸고, 그 직후 한 번
  되돌릴 수 있습니다. 칸 하나에서 바꾼 것은 Ctrl+Z로 되돌립니다.
- 프롬프트 조각 참조(`<세트.조각>`)도 찾습니다. 태그 단위로 찾을 때는 참조 통째(`<HL.캐릭터 눈>`),
  `HL.캐릭터 눈`, 세트 이름, 조각 이름을 각각 태그로 봅니다. 바꾸기는 참조를 통째로 덮는 곳만 바꾸고, 참조의
  일부는 그대로 둡니다(조각 이름은 라이브러리에서 바꾸면 참조도 함께 바뀝니다).

### 가져오기

- **NovelAI PNG**: 창에 놓으면 고를 수 있는 가져오기 창이 열립니다. 고를 수 있는 항목은 다음과
  같습니다.
  - 상위 프롬프트·공통 네거티브(따로 선택). 이 앱에서 만든 이미지면 하위 프롬프트와 추가 프롬프트도
    각자 자리로 돌아갑니다.
  - 설정, 모델, 시드
  - 캐릭터 프롬프트, 감정, 인페인트
  - 새 생성 설정의 이름

  품질 태그와 UC 프리셋은 찾아내 프롬프트에서 뺍니다. 전체 선택·해제도 있습니다.

- **메타데이터가 없는 이미지**: 인페인트의 참고 이미지가 됩니다.
- **JSON 파일**: 검토 창에서 항목마다 새로 추가, 추가 안 함, 덮어쓰기(같은 이름이 있을 때만) 중에
  고릅니다.
- **SD Studio 프로젝트 JSON**: SD Studio에서 생성할 때와 같은 프롬프트가 나오도록 옮깁니다.
  - 이미지 생성 프리셋은 모두 생성 설정이 됩니다. 이지 모드 프리셋은 프로젝트가 고른 것만 가져옵니다
    (SD Studio가 넣어 두는 기본 화풍 프리셋은 빠집니다).
  - 상위·하위 프롬프트는 생성 설정의 상위·하위로, 추가 프롬프트는 작업의 추가 프롬프트로 옮기고 씬 위치는
    「중간」으로 둡니다. 이지 모드의 캐릭터 프롬프트는 상위 뒤, 배경 프롬프트는 하위 앞에 붙고 인원
    태그(`1girl` 등)가 맨 앞으로 갑니다.
  - 프리셋의 시드는 고정 시드로, Variety+는 Variety로 옮깁니다.
  - 고른 프리셋의 켜진 캐릭터 프롬프트는 한 그림의 여러 캐릭터가 되고, 좌표를 쓰면 위치도 옮깁니다.
  - 씬은 조합 칸 그대로 옮겨 칸마다 켜진 후보 하나씩 고른 모든 조합을 생성합니다. 씬 네거티브, 씬
    seed(씬 seed 묶음 포함)도 옮깁니다.
  - 씬 해상도는 가장 많이 쓴 것을 생성 설정 크기로 하고, 다른 씬만 씬 크기를 가집니다.
  - 씬 캐릭터 프롬프트는 같은 번호 캐릭터 뒤에 덧붙입니다(역할 혼합). 씬 전용 모드도 이렇게 옮기고
    알려 줍니다. 역할 네거티브는 씬 네거티브에 합칩니다.
  - 이 모두를 묶은 일반 생성 작업을 하나 만듭니다.
  - 인페인트·i2i 씬, 바이브, 캐릭터 레퍼런스는 그림이 JSON 밖에 있어 가져오지 않습니다.

### 작업 내보내기

사이드바에서 작업을 우클릭해 형식을 고릅니다. 생성 결과는 넣지 않습니다(이미지 내보내기로 따로 내보냅니다).

- **NAI RICE 작업 파일**: 작업과 작업이 쓰는 생성 설정, 캐릭터, 씬 모음, 프롬프트 조각, 인페인트, 바이브,
  캐릭터 레퍼런스를 그림과 함께 담습니다. 다른 PC에서 JSON 파일처럼 가져옵니다.
- **SD Studio 프로젝트**: 생성 설정은 이미지 생성 프리셋 하나가 되고 캐릭터(좌표 포함), 추가 프롬프트,
  고정 시드, 씬과 조합 칸, 쓰는 프롬프트 조각을 담습니다. 인페인트 작업은 일반 생성 씬으로 내보내고, 참고
  이미지·마스크·바이브·캐릭터 레퍼런스는 빠집니다.

품질 태그와 UC 프리셋 문구는 NovelAI 웹이 실제로 붙이는 고정값이라 NovelAI와 마찬가지로 고칠 수 없습니다.
docs.novelai.net과 문구가 다른 곳은 웹을 따릅니다.
모델에 없는 단계나 프리셋은 보이지만 고를 수 없습니다.

## 저장 위치

모든 데이터는 `문서\NAI RICE`에 자동으로 저장됩니다.

```text
NAI RICE/
  library.json                생성 설정, 캐릭터, 감정 모음, 인페인트, 작업, 설정
  backups/                    library.json 자동 백업
  references/<id>/            원본 이미지, 캔버스, 마스크, 그린 층
  projects/<id>/
    generations.json          생성 기록
    inputs/<sha256>.png       대기 중인 작업이 쓰는 고정된 요청 입력
    outputs/<감정>/           잘라 낸 결과(NovelAI 메타데이터가 든 PNG)
    thumbs/  diagnostic/
  exports/
```

0.7 버전 데이터(`workspace.json` + `characters/`)는 처음 실행할 때 `backups/`에 복사한 뒤 자동으로
옮깁니다. JSON 파일은 백업과 주고받기에만 씁니다.

## 비용

Opus 구독이면 면적 1024×1024 이하, 28스텝 이하 생성은 Anlas를 쓰지 않습니다. 기본 해상도 세 가지는
이 조건을 만족하고, 커스텀 크기나 더 많은 스텝은 요청 전에 표시합니다. 시드를 고정하면 변형마다
시드 + n을 써서 같은 이미지가 나오지 않게 합니다.

## 생성 큐

- 요청은 한 번에 하나씩 처리하고, 큐는 아래 막대에 보입니다. 요청 사이에는 정한 간격(0–1000ms,
  기본 300ms)을 둡니다.
- 작업은 바로 시작합니다. 무료 범위를 넘어도 따로 묻지 않고, 예상 Anlas는 생성 버튼 옆과 큐에 보입니다.
- Anlas와 V5 할당량은 작업 앞뒤로, 그리고 창이 보이는 동안 1분마다 다시 읽고 바뀐 값을 아래 막대에
  강조합니다.
- 인증, 할당량, 잘못된 프롬프트, 지원하지 않는 요청 오류는 바로 멈춥니다.
- 요청 제한, 서버, 네트워크 오류는 2초, 5초, 10초 뒤에 다시 시도합니다.
- 큐 상태는 저장됩니다. 다시 실행하면 대기 중이던 작업은 일시 정지되고, 진행 중이던 작업은 중단됨으로
  표시됩니다.
- 작업마다 캔버스와 마스크의 해시 사본을 쓰므로, 대기 중에 마스크를 고쳐도 영향을 받지 않습니다.

## 보안 경계

- 화면(렌더러)의 네트워크 접근은 Content Security Policy로 막혀 있습니다. 이미지는 저장 폴더로
  제한된 읽기 전용 `desk-media://` 프로토콜로 불러옵니다.
- NovelAI 요청은 Electron 메인 프로세스만 정해진 HTTPS 주소로 보냅니다. 토큰 막대용 토크나이저
  파일도 메인 프로세스가 novelai.net의 공개 주소에서 받습니다.
- 토큰은 계정마다 Electron `safeStorage`로 암호화하며 화면 쪽으로 돌려주지 않습니다.

## Windows 빌드

```powershell
npm run package:portable
```

결과물은 `release/`에 만들어집니다. 프로그램을 지워도 저장 폴더는 지워지지 않습니다.

`npm run package:win`은 설치 파일과 포터블 실행 파일을 함께 만듭니다. 두 스크립트 모두
`release/SHA256SUMS.txt`도 만듭니다. GitHub 릴리스에 `.exe` 파일과 함께 올리십시오.

### 받은 파일 확인

실행 파일에 코드 서명이 없어 Windows SmartScreen이 게시자를 알 수 없다고 경고할 수 있습니다. 받은
파일이 배포한 파일과 같은지 확인하려면, 해시를 같은 릴리스의 `SHA256SUMS.txt`에 적힌 값과 비교하십시오.
GitHub에서 받으면 파일 이름의 공백이 `.`으로 바뀌지만 해시 값은 같습니다.

```powershell
certutil -hashfile "받은 파일 이름.exe" SHA256
```

출력된 값이 다르면 실행하지 마십시오.

## NovelAI 프롬프트 대응

| 프로그램 입력란                                  | NovelAI 요청 필드                                            |
| ------------------------------------------------ | ------------------------------------------------------------ |
| 상위 + 추가 + 씬(중간일 때) + 하위 (+ 품질 태그) | `input`, `v4_prompt.caption.base_caption`                    |
| 생성 설정 공통 네거티브                          | `negative_prompt`, `v4_negative_prompt.caption.base_caption` |
| 프롬프트 세트 포지티브 + 감정                    | `characterPrompts[].prompt`, 포지티브 `char_captions`        |
| 프롬프트 세트 네거티브                           | `characterPrompts[].uc`, 네거티브 `char_captions`            |

아래 규칙은 생성 설정마다 정합니다.

- **`reference inset`**: 다음 중 한 곳에 한 번 넣거나 넣지 않습니다.
  - 상위 프롬프트의 앞이나 하위 프롬프트의 끝(품질 태그 앞)
  - 캐릭터 프롬프트의 앞(`girl` 같은 성별 태그 뒤)이나 끝

  프롬프트에 이미 `reference inset`이 있으면 쓴 자리에 그대로 두고 더 넣지 않습니다.

- **감정 프롬프트**: 캐릭터 프롬프트 끝(기본)과 중간(상위·추가 프롬프트와 하위 프롬프트 사이) 중에서
  고릅니다. 순서는 SD Studio와 같습니다: 상위 → 추가 → 감정(중간일 때) → 하위.
  - `|` 자리: 중간이면 SD Studio처럼 상위(+ 추가) 프롬프트에서 쉼표 사이에 `|`만 쓴 곳
    (`1girl, |, masterpiece`)에 감정 프롬프트가 들어갑니다. `|`가 여럿이면 감정 프롬프트도 `|`로 나눠
    차례로 넣고, 남는 것은 상위(+ 추가) 끝 뒤에 붙습니다. `|`가 없으면 상위(+ 추가) 뒤에 붙습니다.
  - 캐릭터 프롬프트에 `|` 자리가 있으면 그 캐릭터 몫의 감정 프롬프트는 늘 그 자리에 들어갑니다.
  - 쓰지 않은 `|` 자리와 하위 프롬프트의 `|`는 NovelAI에 보내지 않습니다. 편집기에서도 흐리게
    보입니다.
  - 1.1.1 이하의 「공통 포지티브의 | 자리」 생성 설정은 마지막 `|` 앞을 상위, 뒤를 하위로 나눠 읽어
    결과가 같습니다. 「공통 프롬프트 끝」은 모두 상위가 되고 중간이 됩니다.

그 밖의 처리는 다음과 같습니다.

- UC 프리셋 문구는 공통 네거티브 앞에 붙습니다. NovelAI 웹처럼 그 앞에 `nsfw`도 붙이는데,
  Curated 모델이거나 포지티브(캐릭터·감정 프롬프트 포함)에 nsfw가 있으면 붙이지 않습니다.
- V3 모델은 캐릭터 프롬프트가 없으므로 캐릭터 프롬프트를 공통 프롬프트 뒤에 붙입니다.
- 색 보정(`color_correct`)은 NovelAI 웹과 같게 보냅니다. i2i와 다듬기는 끄고, 인페인트는 인페인트
  강도가 1보다 낮을 때만 켭니다.
- 작업이 끝날 때마다 계정을 다시 조회해 실제로 쓴 Anlas를 기록합니다.

NovelAI는 외부 서비스입니다. 요청 호환성은 바뀔 수 있으며, 실제 요청에는 사용자 본인의 유효한
토큰과 남은 계정 할당량이 필요합니다.
