# NAI RICE 자세한 설명

짧은 소개와 받는 곳은 [README](../README.md)에 있습니다.

NovelAI 인페인팅(공식 문서의 Reference Inpainting 기법)으로 캐릭터 감정 이미지 세트를 만드는 Windows 데스크톱 프로그램입니다.
캐릭터 참고 이미지를 빈 생성 영역 옆에 놓으면 NovelAI가 그 영역에 같은 캐릭터를 감정별로
그립니다. 결과는 잘라서 감정마다 저장합니다.

NovelAI와 관련이 없는 비공식 프로그램입니다. NAI RICE는 [SD Studio](https://github.com/sunho/SDStudio)(원작 sunho, [현행 Dd154663](https://github.com/Dd154663/SDStudio))에서 파생된 프로젝트입니다. 출처와 사용한
오픈소스 라이브러리의 라이선스는 [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md)에, 변경 내역은
[CHANGELOG.md](../CHANGELOG.md)에 있습니다.

## 구성

다시 쓸 수 있는 네 가지 라이브러리 항목을 **작업**이 하나씩 골라 조합합니다.

```text
생성 설정  +  캐릭터 (+ 프롬프트 세트)  +  감정 모음  +  인페인트
```

- **생성 설정**(코드에서는 `presets`): 공통 포지티브·네거티브 프롬프트, 모델(V5, V4.5
  Full/Curated, V4 Full/Curated, Anime/Furry V3), 샘플러, 스텝, 가이던스, 시드 규칙, NovelAI 품질
  태그(V5는 Standard 또는 Light), UC 프리셋.
- **캐릭터**: 캐릭터 프롬프트 세트(예: 의상마다 하나).
- **감정 모음**: 감정 이름과 프롬프트. 여러 작업에서 함께 씁니다.
- **인페인트**: 캐릭터 참고 이미지와 마스크, 결과 영역.
  - 캔버스: 자동 구성(1216×832, 832×1216, 1024×1024 또는 64의 배수 커스텀 크기)이나 직접 준비한
    캔버스. 자동 구성에서는 참고 영역 안에서 이미지를 전체 보이기나 꽉 채우기로 상단, 중앙, 하단에
    맞추거나, 「자유 배치」로 위치, 크기, 회전, 좌우 반전을 직접 정합니다. 캔버스에서
    Ctrl+T(이미지 변형)를 누르면 포토샵의 자유 변형처럼 끌어서 옮기고 크기를 바꾸고 돌립니다.
  - 분리선: 생성 영역 경계를 따라 선을 그어 결과 쪽이 따로 나뉜 칸임을 알립니다. 색, 두께(8px
    단위), 위치(생성 영역 바깥·경계에 걸침·생성 영역 안쪽), 경계와의 간격을 고릅니다. 바깥에 두면
    NovelAI가 다시 그리지 않아 그대로 남고, 안쪽에 두면 덮어 그려질 수 있습니다.
  - 그리기: i2i 그리기와 같은 도구로 캔버스에 덧칠합니다. 그린 것은 따로 저장되어 배치를 바꿔도
    남고, NovelAI에 보내는 캔버스에 합쳐집니다.
  - 생성: 인페인트 강도. 이 인페인트를 쓰는 작업은 생성 설정의 값 대신 이 값을 씁니다.
- **프롬프트 조각**: 어느 프롬프트에서든 `<세트.조각>`으로 부르는 재사용 문구입니다(SD Studio
  문법). 여러 줄 조각은 이미지마다 시드에 따라 한 줄을 고릅니다. SD Studio 조각 파일과 SD Studio
  프로젝트 안의 조각 라이브러리를 바로 가져올 수 있습니다.
- **작업**: 위 항목을 하나씩 골라 자유롭게 바꿔 조합합니다. 생성 결과, 대표 이미지, 작업별 제외
  감정은 작업에 속합니다.

### 화면

- **감정 갤러리**: 감정마다 대표 이미지나 최신 결과를 보여 줍니다. 카드를 우클릭하면 이름 변경,
  복제, 프롬프트 복사, 결과 폴더 열기, 삭제를 할 수 있습니다.
- **라이브러리·작업 목록**: 끌어서 놓아 순서를 바꾸고, 두 번 클릭하거나 우클릭해 이름을 바꿉니다.
- **여러 개 선택**: 라이브러리·작업 목록과 감정 갤러리의 빈 곳을 끌면 상자로 여러 항목을 고릅니다(Ctrl·Shift
  클릭도 됩니다). 고른 항목은 Delete 키나 「삭제」 버튼으로 한꺼번에 지웁니다.
- **태그 자동완성**: 프롬프트 칸에 입력하면 단부루 태그 후보가 게시물 수와 함께 뜹니다. Tab이나 Enter로
  넣고, `artist:`로 시작하면 작가만 찾습니다. 태그 목록이 프로그램에 들어 있어 인터넷 없이 동작합니다.
- **단축키**: 숫자 키 1 작업, 2~8 라이브러리(글을 쓰는 중에는 숫자가 그대로 입력됩니다), F1 단축키 보기, F2 이름
  바꾸기, F5 새로 고침, F6 이미지 목록, F7 왼쪽 패널, F8 히스토리, F11 전체 화면, Ctrl+F 찾기, Ctrl+H 찾아
  바꾸기, Ctrl++/-/0·Ctrl+휠 확대, Ctrl+Tab 다음 작업 등. 패널 키는 Lightroom과 같습니다. 전체 목록은 프로그램
  설정 › 단축키에 있습니다.
- **토큰 막대**: 프롬프트 패널 아래에 실제로 보낼 포지티브·네거티브의 토큰 수를 모델 한도(V5 Full 1471,
  V5 Curated 703, V4·V4.5 512, V3 225)와 함께 막대로 보여 줍니다. 품질 태그, 씬, 모든 캐릭터 프롬프트를 합친
  수이고, 씬이 여럿이면 가장 긴 씬 기준입니다. 한도를 넘으면 빨갛게 바뀌고 뒤쪽이 잘립니다. NovelAI 웹과
  같은 토크나이저를 쓰며, 모델 종류마다 처음 한 번 novelai.net에서 받아 둡니다(토큰은 쓰지 않습니다).
- **히스토리**: 작업과 자유 생성 화면 오른쪽 끝에 NovelAI 웹처럼 최근 결과부터 세로로 보여 줍니다.
  누르면 그 결과를 열고(작업은 그 씬의 상세 화면), F8로 접습니다.
- **사이드바·왼쪽 패널**: 사이드바와 라이브러리 목록은 접기 버튼(‹)을 누를 때마다 펼침 → 아이콘만 → 숨김
  순으로 바뀌고, 프롬프트 패널은 펼침과 숨김만 오갑니다(사이드바 Ctrl+B, 프롬프트 패널·라이브러리 목록 F7).
  숨긴 사이드바는 창 맨 위 줄 왼쪽 버튼으로, 숨긴 프롬프트 패널과 라이브러리 목록은 화면 머리줄 왼쪽 끝에 생기는 그 패널
  아이콘(›)으로 다시 엽니다.
- **입력 패널**: 씬 상세, 자유 생성, 인페인트 편집의 오른쪽 입력 패널은 머리줄 오른쪽의 조절 아이콘으로
  숨기고 다시 엽니다. 숨기는 동안 생성 버튼은 작은 떠 있는 창으로 옮겨 갑니다. 이 창은 왼쪽 점 손잡이를 끌어
  원하는 곳에 두면 다음에도 그 자리에 뜨고, 아이콘만 있어 버튼 설명은 마우스를 올리면 나옵니다.
- **집중 모드**: 입력 칸 밖에서 Tab을 누르면 패널을 한 번에 숨기고, 다시 누르면 숨기기 전으로 돌아옵니다
  (포토샵·Lightroom과 같은 키). 창 맨 위 줄 오른쪽의 네 모서리 버튼으로도 켜고 끕니다. 숨긴 패널은 단축키나
  버튼으로 하나씩 다시 열 수 있습니다. 씬 상세에서 다음 씬으로 넘기는 키는 PageUp·PageDown입니다. 숨기는 범위는
  프로그램 설정 › 화면 · 테마에서 그림을 보고 고릅니다.
  - 패널만(기본): 사이드바, 왼쪽 패널, 히스토리
  - 입력 패널까지: 오른쪽 입력 패널도 숨기고, 생성 버튼은 떠 있는 창으로 옮깁니다.
  - 모두: 생성 큐 막대도 숨기고, 큐 상태·일시 중지·실패 재시도 버튼도 떠 있는 창에 둡니다.
- **숨긴 패널 잠깐 보기**: 같은 설정 화면에서 「창 가장자리에 마우스를 대면 숨긴 패널을 잠깐 겹쳐 보이기」를
  켜면, 숨긴 패널이 창 왼쪽·오른쪽 끝에 마우스를 대는 동안 내용 위에 겹쳐 보이고 벗어나면 다시 숨습니다.
  인페인트 캔버스 가장자리를 칠할 때 튀어나올 수 있어 기본은 꺼져 있습니다.
- **프로그램 설정**: 토큰, 요청 간격, 파일 이름, 내보내기, 태그 참고, 백업, 단축키 설정은 창 맨 위 줄
  오른쪽 버튼으로 엽니다.
- **저장 공간**: 프로그램 설정 › 저장 공간 · 백업에서 작업별 용량을 보고, 대표(★) 이미지를 뺀 결과를
  한꺼번에 정리하거나 기록과 파일이 맞는지 점검합니다. 지운 결과는 Windows 휴지통으로 갑니다.
- **테마**: 색 테마 다섯 가지를 다크·라이트 모드(또는 Windows 설정 따르기)로 쓸 수 있습니다. 창
  제목 표시줄도 테마를 따릅니다.

### 프롬프트 입력

프롬프트 입력란은 NovelAI V4.5/V5 문법(`{}`, `[]`, 숫자 가중치, `::`)을 색으로 구분하고, 커서 옆
괄호의 짝을 보여 줍니다. 다음 문제를 목록으로 알려 줍니다.

- 짝이 맞지 않는 괄호
- 끝나지 않은 가중치
- 없는 프롬프트 조각

긴 프롬프트는 크게 보기 창에서 편집합니다. Ctrl+Enter로 적용하고 Esc로 취소합니다.

**찾기·바꾸기**: Ctrl+F로 찾고 Ctrl+H로 바꿉니다. 찾는 범위는 세 가지입니다.

- **이 칸**: 프롬프트 칸에서 누르면 그 칸에서만 찾습니다.
- **이 항목**: 라이브러리에서 연 항목 하나(예: 씬 모음 하나), 또는 자유 생성 화면에서 찾습니다. 라이브러리
  편집 화면에서 누르면 이 범위로 열립니다.
- **라이브러리 전체**: 생성 설정, 캐릭터, 씬 모음, 프롬프트 조각, 자유 생성의 프롬프트를 모두 찾습니다.

찾은 곳은 주황색으로 칠해지고 Enter·F3으로 다음, Shift+Enter·Shift+F3으로 이전 곳으로 갑니다.

- **태그 단위**(기본으로 켜짐): 쉼표로 나뉜 태그와 통째로 같을 때만 찾습니다. `hair`는 `silver hair`나
  `hairband`에 걸리지 않습니다. 괄호·가중치 안의 태그도 찾고, 대소문자는 가리지 않습니다. 바꿀 내용을
  비우면 그 태그와 붙어 있던 쉼표를 함께 지웁니다.
- **이름만**(기본으로 꺼짐): 프롬프트 대신 이름에서 찾고 바꿉니다. 라이브러리 항목 이름과 그 안의
  프롬프트 세트·씬·조각 이름이 대상입니다. 이름은 태그 단위와 관계없이 글자가 들어 있으면 찾습니다
  (「기본」으로 「기본 씬 6종」을 찾습니다). 결과를 누르면 그 이름 칸으로 가서 찾은 글자를 고릅니다. 바꾸면
  비게 되는 이름은 그대로 두고, 조각 이름을 바꾸면 `<세트.조각>` 참조도 함께 바뀝니다.
- **생성 기록 포함**(기본으로 꺼짐, 라이브러리 전체에서만): 이미 만든 결과에 실제로 보낸 프롬프트에서도
  찾습니다. 최신 200개까지
  보여 주고, 누르면 그 결과를 엽니다. 기록은 바꾸지 않습니다.
- 「이 항목」·「라이브러리 전체」 바꾸기는 몇 칸에서 몇 개를 바꾸는지 확인한 뒤 바꾸고, 그 직후 한 번
  되돌릴 수 있습니다. 칸 하나에서 바꾼 것은 Ctrl+Z로 되돌립니다.
- 프롬프트 조각 참조(`<세트.조각>`) 안의 글자는 찾지 않습니다. 조각 이름은 라이브러리에서 바꾸면 참조도
  함께 바뀝니다.

### 가져오기

- **NovelAI PNG**: 창에 놓으면 고를 수 있는 가져오기 창이 열립니다. 고를 수 있는 항목은 다음과
  같습니다.
  - 공통 포지티브·네거티브(따로 선택)
  - 설정, 모델, 시드
  - 캐릭터 프롬프트, 감정, 인페인트
  - 새 생성 설정의 이름

  품질 태그와 UC 프리셋은 찾아내 프롬프트에서 뺍니다. 전체 선택·해제도 있습니다.

- **메타데이터가 없는 이미지**: 인페인트의 참고 이미지가 됩니다.
- **JSON 파일**: 검토 창에서 항목마다 새로 추가, 추가 안 함, 덮어쓰기(같은 이름이 있을 때만) 중에
  고릅니다.

품질 태그와 UC 프리셋 문구는 NovelAI 웹이 실제로 붙이는 고정값이라 NovelAI와 마찬가지로 고칠 수 없습니다.
docs.novelai.net과 문구가 다른 곳은 웹을 따릅니다.
모델에 없는 단계나 프리셋은 보이지만 고를 수 없습니다.

## 저장 위치

모든 데이터는 `문서\NAI RICE`에 자동으로 저장됩니다.

```text
NAI RICE/
  library.json                생성 설정, 캐릭터, 감정 모음, 인페인트, 작업, 설정
  backups/                    library.json 자동 백업
  references/<id>/            원본 이미지, 캔버스, 마스크, 그린 층
  projects/<id>/
    generations.json          생성 기록
    inputs/<sha256>.png       대기 중인 작업이 쓰는 고정된 요청 입력
    outputs/<감정>/           잘라 낸 결과(NovelAI 메타데이터가 든 PNG)
    thumbs/  diagnostic/
  exports/
```

0.7 버전 데이터(`workspace.json` + `characters/`)는 처음 실행할 때 `backups/`에 복사한 뒤 자동으로
옮깁니다. JSON 파일은 백업과 주고받기에만 씁니다.

## 비용

Opus 구독이면 면적 1024×1024 이하, 28스텝 이하 생성은 Anlas를 쓰지 않습니다. 기본 해상도 세 가지는
이 조건을 만족하고, 커스텀 크기나 더 많은 스텝은 요청 전에 표시합니다. 시드를 고정하면 변형마다
시드 + n을 써서 같은 이미지가 나오지 않게 합니다.

## 생성 큐

- 요청은 한 번에 하나씩 처리하고, 큐는 아래 막대에 보입니다. 요청 사이에는 정한 간격(0–1000ms,
  기본 300ms)을 둡니다.
- 작업은 바로 시작합니다. 무료 범위를 넘어도 따로 묻지 않고, 예상 Anlas는 생성 버튼 옆과 큐에 보입니다.
- Anlas와 V5 할당량은 작업 앞뒤로, 그리고 창이 보이는 동안 1분마다 다시 읽고 바뀐 값을 아래 막대에
  강조합니다.
- 인증, 할당량, 잘못된 프롬프트, 지원하지 않는 요청 오류는 바로 멈춥니다.
- 요청 제한, 서버, 네트워크 오류는 2초, 5초, 10초 뒤에 다시 시도합니다.
- 큐 상태는 저장됩니다. 다시 실행하면 대기 중이던 작업은 일시 정지되고, 진행 중이던 작업은 중단됨으로
  표시됩니다.
- 작업마다 캔버스와 마스크의 해시 사본을 쓰므로, 대기 중에 마스크를 고쳐도 영향을 받지 않습니다.

## 보안 경계

- 화면(렌더러)의 네트워크 접근은 Content Security Policy로 막혀 있습니다. 이미지는 저장 폴더로
  제한된 읽기 전용 `desk-media://` 프로토콜로 불러옵니다.
- NovelAI 요청은 Electron 메인 프로세스만 정해진 HTTPS 주소로 보냅니다. 토큰 막대용 토크나이저
  파일도 메인 프로세스가 novelai.net의 공개 주소에서 받습니다.
- 토큰은 Electron `safeStorage`로 암호화하며 화면 쪽으로 돌려주지 않습니다.

## Windows 빌드

```powershell
npm run package:portable
```

결과물은 `release/`에 만들어집니다. 프로그램을 지워도 저장 폴더는 지워지지 않습니다.

`npm run package:win`은 설치 파일과 포터블 실행 파일을 함께 만듭니다. 두 스크립트 모두
`release/SHA256SUMS.txt`도 만듭니다. GitHub 릴리스에 `.exe` 파일과 함께 올리십시오.

### 받은 파일 확인

실행 파일에 코드 서명이 없어 Windows SmartScreen이 게시자를 알 수 없다고 경고할 수 있습니다. 받은
파일이 배포한 파일과 같은지 확인하려면, 해시를 같은 릴리스의 `SHA256SUMS.txt`에 적힌 값과 비교하십시오.
GitHub에서 받으면 파일 이름의 공백이 `.`으로 바뀌지만 해시 값은 같습니다.

```powershell
certutil -hashfile "받은 파일 이름.exe" SHA256
```

출력된 값이 다르면 실행하지 마십시오.

## NovelAI 프롬프트 대응

| 프로그램 입력란                       | NovelAI 요청 필드                                            |
| ------------------------------------- | ------------------------------------------------------------ |
| 생성 설정 공통 포지티브 (+ 품질 태그) | `input`, `v4_prompt.caption.base_caption`                    |
| 생성 설정 공통 네거티브               | `negative_prompt`, `v4_negative_prompt.caption.base_caption` |
| 프롬프트 세트 포지티브 + 감정         | `characterPrompts[].prompt`, 포지티브 `char_captions`        |
| 프롬프트 세트 네거티브                | `characterPrompts[].uc`, 네거티브 `char_captions`            |

아래 규칙은 생성 설정마다 정합니다.

- **`reference inset`**: 다음 중 한 곳에 한 번 넣거나 넣지 않습니다.
  - 공통 포지티브의 앞이나 끝(품질 태그 앞)
  - 캐릭터 프롬프트의 앞(`girl` 같은 성별 태그 뒤)이나 끝

  프롬프트에 이미 `reference inset`이 있으면 쓴 자리에 그대로 두고 더 넣지 않습니다.

- **감정 프롬프트**: 캐릭터 프롬프트 끝(기본)이나 공통 프롬프트 끝에 붙입니다.

그 밖의 처리는 다음과 같습니다.

- UC 프리셋 문구는 공통 네거티브 앞에 붙습니다. NovelAI 웹처럼 그 앞에 `nsfw`도 붙이는데,
  Curated 모델이거나 포지티브(캐릭터·감정 프롬프트 포함)에 nsfw가 있으면 붙이지 않습니다.
- V3 모델은 캐릭터 프롬프트가 없으므로 캐릭터 프롬프트를 공통 프롬프트 뒤에 붙입니다.
- 색 보정(`color_correct`)은 NovelAI 웹과 같게 보냅니다. i2i와 다듬기는 끄고, 인페인트는 인페인트
  강도가 1보다 낮을 때만 켭니다.
- 작업이 끝날 때마다 계정을 다시 조회해 실제로 쓴 Anlas를 기록합니다.

NovelAI는 외부 서비스입니다. 요청 호환성은 바뀔 수 있으며, 실제 요청에는 사용자 본인의 유효한
토큰과 남은 계정 할당량이 필요합니다.
